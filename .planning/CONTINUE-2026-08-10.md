## 1. 오늘 뒤집힌 전제 — 한 줄

어제 브리핑은 "표시 순간이 하필 제일 티 안 나는 순간"이라고 했다. 재보니 그게 아니라
**사진이 애초에 감점을 잰 순간이 아닌 곳에서 찍히고 있었다.** 뿌리 = **fps 라벨 오차.**

```
frame_extractor.py:44   step = max(1, round(src_fps / target_fps))   ← 정수 step
                        → 실제 산출 rate = src_fps / step  ≠  target_fps
pipeline/app.py         video_sec = frame_idx / target_fps(9.0)      ← 요청값을 씀
compare_align.py:262    ui = clip(round(atVideoSec * 15), ...)        ← 재탐색 없이 클램프
```

30fps 원본 → step 3 → 실제 **9.997fps**. 저장 초가 **9.7~10.0% 크다.**
저장 트랙 프레임 수가 이 규칙으로 **4/4 케이스 정확 재현**(180/182/62/83) = 추측 아님.
기준 트랙은 **11건 전수** 실제 14.88~15.00fps인데 라벨 전부 18.0.
