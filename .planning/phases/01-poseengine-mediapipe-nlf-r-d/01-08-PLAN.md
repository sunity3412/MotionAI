## 아키텍처 결정 — MediaPipeWithLifterEngine

기존 PoseEngine Protocol (interfaces.py) 시그니처:
```python
class PoseEngine(Protocol):
    def estimate(self, frames: np.ndarray, pole_axis: PoleAxis) -> list[PoseFrame]: ...
```

`MediaPipeWithLifterEngine.estimate(frames, pole_axis)` 는 같은 시그니처 유지:
1. MediaPipe 2D 추출 (기존 MediaPipePoseEngine 재사용)
2. MP 33 → H3.6M 17 변환 (pose_lifters 어댑터 호출)
3. MotionBERT inference (T frames batch)
4. H3.6M 17 → COCO-17 역변환 + 기존 PoseFrame 으로 wrap
5. pole_axis 메타 보존 (H-3)

→ 호출하는 쪽 코드(compare_engines, pipeline) 는 PoseEngine 인터페이스로만 보니까 변경 최소.
