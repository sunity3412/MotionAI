**T-1-2**: 가설 (a) Frame-mean 한계 trace — Pod 에서 실행 시 (영상별):
  - RTMPose+MB chain: spike_rtmpose 패턴 그대로 — frames → RTMPose 2D → COCO→H36M → MotionBERT lift → `_h36m17_to_coco17_subset` → `compute_joint_angles` → `(T, J)` matrix.
  - NLF chain: `pose_estimator.NLFPoseEstimator.estimate` → `(T, J)` matrix (같은 features.compute_joint_angles 거침).
  - 두 (T, J) 행렬에서 frame별 12 joint angle 차이 dump — 평균 / 분포 / "두 엔진이 같은 frame 에서 같은 angle 인 frame 비율" 계산.
  - 출력: `{"motion": ..., "hypothesis_a": {"frame_count": T, "joint_disagreement_per_frame": [...], "mean_disagreement": x, "peak_disagreement_frame_idx": k}}`.

**T-1-3**: 가설 (c) NLF baseline 영상별 편차 trace — sweep_report 입력만으로 가능:
  - 영상별 NLF dimensions 분포: stability/line/angle 값 비교. NLF 가 영상마다 다른 dimension 구성 (특히 line/angle 의 None 분포).

  - 출력: `{"hypothesis_c": {"nlf_overall_range": [min, max], "nlf_dim_variance": {...}, "nlf_nan_rate_per_joint": [...]}}`.

**T-1-4**: 가설 (d) keypoint 매핑 차이 trace — 로컬 실행 가능 (Pod 의존 X):
  - `rtmpose_to_h36m17.JOINT_KEYS` (h36m 17) 순서 + derive 규칙 (hip = (left_hip + right_hip)/2, etc.) dump.
  - `sunity_shared.analysis.skeleton.JOINT_KEYS` (NLF 출력) 순서 dump.
  - 두 17-joint 정의 차이 표 출력. `_h36m17_to_coco17_subset` 도 같이 dump (RTMPose+MB chain 의 최종 17 joint).

**T-1-5**: argparse — `--sweep-report <path>` (T-1-1 1차 입력, 필수), `--motions <list>` (Pod live trace 시), `--bucket sunity-motion-pilot-videos`, `--rtmpose-config / --rtmpose-checkpoint / --motionbert-root / --motionbert-weights` (Pod live trace 시, Plan 10/11 와 동일), `--mode {report-only,live}` (report-only 기본 = sweep JSON 만 분석, live = Pod 영상 처리), `--out <path>` (default = `backend/research/spikes/reports/debug_gap_<UTC ts>.json` + `.md` sibling).
