## IPSF Code of Points 핵심 객관 수치 (이미 박제됨)

| 항목 | IPSF 수치 | 출처 |
|---|---|---|
| 각도 tolerance (Full Mark) | ±20° (규정 각도 기준) | 폴스포츠-지식.md:311 |
| tolerance 초과 시 감점 | -0.2점 | 폴스포츠-지식.md:311 |
| 4대 심사 섹션 | 기술 보너스 / 기술 감점 / 예술 및 안무 / 필수 요소 | 폴스포츠-지식.md:70 |
| 발 형태 | Pointed feet (Flexed 금물) | 폴스포츠-지식.md:533 |

본 plan 의 phase별 GeometricCriterion 은 위 객관 수치 + 동작별 target angle (예: invert hold 무릎 180°, climb 시 손-어깨 정렬 등) 으로 구성. belle 가 IPSF 규정에서 phase별 target 을 lookup 해서 명시화.

## GeometricCriterion YAML 예시 (template, 실 수치는 belle)

```yaml
# backend/judging_data/criteria/ref-invert.yaml
motion: ref-invert
source: "IPSF Code of Points 2024 — invert family"
criteria:
  hold_moment:
    - joint: left_knee
      angle_target: 180.0      # 완전 펴짐 (invert hold)
      tolerance_full: 20.0     # IPSF 표준 ±20° (-0.2점 감점)
      deduction_per_step: 0.2
      minimum_requirement: 130.0
      source_ref: "폴스포츠-지식.md:311 + IPSF Code of Points §4.2.1"
    - joint: right_knee
      angle_target: 180.0
      tolerance_full: 20.0
      deduction_per_step: 0.2
      minimum_requirement: 130.0
      source_ref: "..."
    # ... 다른 joint
  setup_moment: []   # 별도 phase 임계값
  release_moment: []
```

  - 필드: `motion: str`, `moment_key: str`, `joint_key: str`, `angle_target: float`, `tolerance_full: float`, `deduction_per_step: float`, `minimum_requirement: float`, `source_ref: str`.
  - `validate()` 메서드 — IPSF 객관성 가드:
    - `tolerance_full > 0`
    - `deduction_per_step > 0`
    - `0 ≤ angle_target ≤ 360`

    - `source_ref` 비어있지 않음 (객관 인용 의무화)
    - `moment_key` ∈ {`setup`, `hold`, `peak`, `release`} (Plan 13 와 호환)
