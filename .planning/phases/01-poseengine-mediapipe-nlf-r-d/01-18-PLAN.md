## 본 plan averaging strategy 2개

### STRATEGY_MEAN (frame-wise nanmean)

```
averaged[t, j] = np.nanmean([rtmpose[t, j], mediapipe[t, j]])
```

- 단순 평균. NaN-aware (한 path NaN, 다른 path 정상이면 정상값 사용).
- 가장 단순. 두 path 의 노이즈가 zero-mean 이면 효과적.
- 가설: Plan 16 (d) cross-engine 34.57° 의 두 path 가 서로 다른 방향으로 격차 → mid-point 가 진실에 가깝.

### STRATEGY_AGREEMENT_GATED (disagreement-aware averaging)

```
if |rtmpose[t, j] - mediapipe[t, j]| < AGREEMENT_THRESHOLD_DEG:
    averaged[t, j] = np.nanmean([rtmpose[t, j], mediapipe[t, j]])
else:
    averaged[t, j] = NaN  # temporal_fill 가 보간
```

- AGREEMENT_THRESHOLD_DEG = 30.0 (Plan 16 HYPOTHESIS_D_CROSS_ENGINE_DISAGREEMENT_STRONG_DEG 와 동일).
- 두 path 가 일치할 때만 평균 사용, 불일치 시 NaN → temporal_fill 보간으로 회복.
- 가설: occlusion / 접힌 자세에서 한쪽 path 가 명백히 틀어진 경우 둘의 평균은 여전히 틀어져 있음. 둘 다 일치하는 frame 만 신뢰 + 나머지는 시간 보간이 더 안정.
