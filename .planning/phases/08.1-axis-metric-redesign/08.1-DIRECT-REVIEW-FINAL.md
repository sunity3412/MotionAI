Phase 08.1 is now ready to execute.

The core issues from Phase 8 are addressed:

- The invalid global distance metric is deleted rather than recalibrated.
- Tilt is explicitly an unsigned body-line orientation signal in `[0, 90]`.
- Operational calibration is `P100 + margin`, not P90.
- Boundary values stay low.

This is no longer a No-Go planning state. Remaining items are small execution hygiene, not phase blockers.

This matches the new YAML schema.

### Cleared: Boundary-Low Severity

- `tilt > medium + 1e-9` -> medium

This matches the P100 + margin calibration strategy.

### Cleared: Unsigned Tilt Contract

The compute snippet now removes `abs()` and explicitly treats shoulder/hip tilt as already unsigned `[0, 90]`.

This is better than swallowing a future signed value silently.

### Cleared: Option B Production Fallback Risk

This closes the circular threshold-chasing path.

### Cleared: Weak Wave 2 Acceptance
