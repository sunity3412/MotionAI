### MEDIUM: `abs()` Remains In The Tilt-Only Snippet

The plan correctly states all tilt values are unsigned `[0, 90]`. The compute snippet still passes:

```python
abs(shoulder_tilt_val)
abs(hip_tilt_val)
```

Concrete references:

- `08.1-01-PLAN.md:393-399`

This is not harmful if the helpers truly always return unsigned values. But it slightly weakens the contract because a future signed value would be silently swallowed rather than tested.

Recommended cleanup:

- Remove `abs()` in the snippet.
- Add a test that asserts all produced tilt values are either `None` or `0 <= tilt <= 90`.
- Keep signed direction as a future separate field if needed.

### MEDIUM: YAML Loader Swallows Schema Errors Into Fallback

The loader now validates `schema_version=2`, `calibration_method`, and `null_tilt_verified`, which is good. But it catches `ValueError` and falls back to default thresholds.

Concrete references:

- `08.1-01-PLAN.md:285-308`

For local import safety, fallback is acceptable. For production, Wave 2 catches fallback via `tilt_thresholds_fallback`. Still, during unit tests a malformed YAML could be treated as fallback unless the test checks the warning.

Recommended cleanup:

- Keep missing file fallback.
- For malformed present YAML, consider returning fallback with `tilt_thresholds_fallback` plus `tilt_thresholds_invalid`, or raise in tests/production.
- At minimum, add a loader test for "invalid schema v2 file produces fallback warning".

### LOW-MEDIUM: README/Context/ROADMAP Short Labels Still Emphasize P90

The operational logic is now P100 + margin. Some summaries still mention P25/P75/P90 more prominently than P100:

- `08.1-CONTEXT.md` is mostly fixed but still opens the calibration bullet as P25/P50/P75/P90 distribution.
- `.planning/ROADMAP.md:272` says P25/P75/P90 but not P100 + margin.

This will not break execution, but the roadmap will mislead future readers.

Recommended cleanup:

- Change roadmap one-liner to: `P25/P50/P75/P90/P100 distribution + P100+margin operational cutoff`.
- Make context D-02 explicitly say P90 is visibility only.
