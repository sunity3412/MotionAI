## Summary

Phase 8 의 `compute_axis_deviation` 가 산출한 pelvis distance 값이 도메인 정합성을 위반 (정은지 5/5 영상 모든 phase severity='high'). 본 research 는 IPSF Code of Points 2024-2025 / 2025-2027 + 폴스포츠-지식.md 종합 lookup 으로 다음 **3 가지 핵심 발견** 박제:

1. **IPSF 는 "축 이탈 (axis deviation)" 을 글로벌 deduction 항목으로 정의하지 않는다.** 'Tilt', 'Lean', 'Off-axis' 라는 단어는 규정집에 존재하지 않음 (NotebookLM citation 9 / Page 87 Glossary). 'Twist' 는 척추 회전 (body position) 한정.
2. **IPSF 의 axis-관련 평가는 "기술 조건부 (technique-conditional)"** — 동작 종류별 Criteria 가 "폴과 90° 각도 (±20° tolerance)" 또는 "폴에서 떨어진 상태 (away from pole)" 등을 명시 (예: S55 Iron X, F94 Mexican Flag, F12 Cross Bow Elbow Hold, Dead Lift). **글로벌 거리/각도 임계값 없음.**
3. **Phase 8 의 가정** ("어떤 동작에서든 pelvis 가 폴 축에서 가까울수록 좋다") **는 폴스포츠 도메인에서 거짓.** 정은지의 ref-invert / ref-foxtop-split 처럼 인버트 + 스플릿 동작은 pelvis 가 폴 축에서 멀리 떨어진 것이 **정답** (S55 Iron X criteria: hips bent forwards, body 90° to pole — pelvis 는 폴축에서 떨어져야 함). Phase 8 의 global distance threshold (0.15, 0.30) 는 IPSF 도메인의 어떤 항목과도 매핑되지 않음.

**Primary recommendation:**
**α-4 (tilt-only metric + global distance 차원 제거) + β-2 변형 (IPSF deduction 카테고리 기반, 단 distance 가 아닌 tilt 임계값에 적용)** 의 조합.

근거: IPSF 는 distance metric 자체를 글로벌 채점 항목으로 인정하지 않으므로 (a) global pelvis distance 차원을 제거하는 것이 도메인 정합 결정. (b) tilt (rotation-only, origin-invariant) 만 보존하면 Phase 9 평행 진입 가능 (PHASE8-INHERITED-ISSUES §3.2 보장). (c) "기술 조건부 distance" (예: Iron X 의 "body 90° to pole") 가 정말 필요하다면 Phase 9 의 ForceDirectionPattern 또는 Phase 11 의 GeometricCriterion 으로 이관 — Phase 8.1 scope 가 아님.

단, 본 추천은 discuss-phase / belle 최종 결정이 우선. α-2 (pole 검출 위치 → origin 매핑) 는 카메라 calibration 비용 대비 가치가 불명확하지만 belle 가 "distance 차원이 반드시 필요" 라고 판단하면 검토 가능.

## 2. IPSF Code of Points Findings (NotebookLM lookup 2026-06-09)

### 2.1 핵심 발견 — "축 이탈" 용어 자체가 IPSF 규정에 없음

**NotebookLM Query 1 인용** (citation 9, Pole Sports CoP Glossary):

> "규정집에는 특정 축에서 기울어짐을 뜻하는 'Tilt', 'Lean', 'Off-axis' 라는 단어를 사용한 전용 감점 항목은 존재하지 않습니다."
> "IPSF 는 신체 축의 변화나 공간적 방향을 서술할 때 이러한 모호한 표현 대신 Inverted (거꾸로 매달림), Upright (직립), Horizontal (수평), Back arch (후굴), Twist (척추 수직축 회전) 등 철저히 해부학적이고 공간적인 공식 상태 (Body position) 명칭만을 엄격하게 사용합니다."

**의미**: Phase 8 의 `AxisDeviationMetric` 이 도메인 용어 매핑이 없음. IPSF 가 평가하는 axis 관련 항목은 **(a) Twist body position 위반** + **(b) Posture / Body line 불량 (-0.2)** + **(c) 동작별 Criteria 위반 (예: Iron X 의 "body 90° to pole ±20°")** 셋뿐.

### 2.2 IPSF 가 명시하는 axis-관련 deduction 항목 (3 카테고리)

| # | 항목 | Deduction | Page | Citation |
|---|------|-----------|------|----------|
| A | **Rounded shoulders / back** (굽은 어깨/등) — posture & extension 불량 | **-0.2** | Pole Sports CoP Page 21 | NotebookLM Query 1 결론 |
| B | **Body line 불량** (knee-toe alignment / 라인 확장 부족) | **-0.2** | Pole Sports CoP Page 21 | NotebookLM Query 1 결론 |
| C | **Poor presentation of the element** (심판이 동작 전체를 볼 수 없는 각도/위치) | **-0.5** | Aerial Pole CoP 2024-2025 **Page 10** | NotebookLM Query 1 citation 1, 2 |

**주의**: A/B 는 신체 라인 (어깨/등의 형상) 평가. Phase 8 의 pelvis distance / tilt 와 직접 매핑 안 됨. C 는 카메라/관객 시점 문제이지 dancer 의 축 이탈 문제가 아님.

### 2.3 IPSF 의 "기술 조건부" axis 평가 (NotebookLM Query 2)

각 element 의 Criteria 가 "폴과의 각도" 또는 "폴로부터 떨어진 정도" 를 직접 명시:

#### 2.3.1 "폴에서 떨어진 상태 (away from pole)" 가 평가 기준인 동작

| Element | Criteria 인용 | Citation |
|---------|--------------|----------|
| **Dead Lift (DL)** | "The body should be extended away from the aerial pole before moving into the dead lift" | Aerial Pole CoP Page 91, 101 (citations 1, 4) |
| **Aerial Dead Lift (ADL)** | "The body should be fixed and suspended away from the pole and the legs parallel to the pole" | Aerial Pole CoP Page 101 (citation 4) |
| **SP86 One-Handed Parallel Split Spin** | "upright, away from the pole, parallel to the pole" | (citation 4, 5) |
| **SP90 Supported Sailor Back Bend** | "inverted and suspended away from the pole" | (citation 4, 5) |
| **S54 Forearm Grip Butterfly** | "torso is facing the pole, hips are away from the pole" | (citation 6, 7) |

→ **이 동작들에서는 pelvis 가 폴축에서 멀어진 것이 점수의 정답**. Phase 8 의 "pelvis 가 폴 가까이 = severity low" 가정과 정반대.

#### 2.3.2 "폴과 90° 각도" 가 평가 기준인 동작 (절대 각도, ±20° tolerance)

| Element | Criteria 인용 | Citation |
|---------|--------------|----------|
| **S55 Iron X 1** | "upper body is at a 90° angle to the pole with a tolerance of not more of 20°" | Aerial Pole CoP Page 63 (citation 6) |
| **S53 Flag Grip Pencil** | "body is at a 90° angle to the pole" | (citation 6, 7) |
| **F12 Cross Bow Elbow Hold** | "Upper body must be at a 90° angle to the pole and parallel to the floor" | (citation 10, 11, 12) |

→ **각도 평가의 단위는 "폴과의 각도", "지면과의 평행" 이지 "pelvis 의 폴축까지 거리" 가 아님**.

#### 2.3.3 "Body position" 정의 (Inverted / Upright / Horizontal / Twist)

| Position | 정의 | 정량 임계값 |
|----------|------|------------|
| **Inverted** | 거꾸로 매달림 — 해부학적 (골반이 머리보다 위) | **정량 임계값 없음** (NotebookLM Query 2 결론) |
| **Upright** | 직립 — 해부학적 | **정량 임계값 없음** |
| **Horizontal** | 폴과 90° + ±20° tolerance | **존재** (각 element Criteria 별) |
| **Twist** | "rotation on the vertical axis of the spine. The shoulders and the hips do not face the same direction" | Aerial Pole CoP **Page 87 Glossary** (citations 3, 15, 16) — 정성 정의 |

→ **Inverted / Upright 의 폴 축 기준 각도 임계값 없음**. "axis 정렬" 의 글로벌 metric 으로 사용할 IPSF 정량 기준 = **부재**.

### 2.4 폴스포츠-지식.md 종합 (보고서 2~6)

`docs/research/폴스포츠-지식.md` 의 IPSF Code of Points 관련 인용 정리:

- **보고서 2 §2.3** (전략적 라인 관리, line 264~273): "굽은 어깨나 등" (-0.2), "팔다리 완전한 신장" (-0.2), "긴장으로 인한 손가락/발가락 움츠러듦" (-0.2). → 모두 **신체 라인** (extension/posture) 항목.
- **보고서 3 §3.1** (감점 5요소, line 397~403): 무릎/발가락 정렬 / 라인 / 확장 / 자세 / 신체 배치. → "신체 배치 (Body placement)" 가 가장 axis 와 가깝지만 정의는 "기술 기준 (Criteria) 에 적합하지 않은 위치". 글로벌 axis distance 가 아닌 **technique-specific**.

**최종 결론**: 폴스포츠-지식.md 와 NotebookLM IPSF lookup 양쪽이 일치. **글로벌 "pelvis distance from pole axis" 차원은 IPSF 도메인 매핑 없음**.

## 3. 폴스포츠 도메인 "축 이탈" 정의 — 종합

폴스포츠 도메인에서 "축 이탈 (axis deviation)" 이라는 표현이 사용될 때, 다음 **3 가지 의미** 중 하나:

### 3.1 의미 ① — Twist body position (정성)
척추의 수직축을 중심으로 한 회전. 어깨와 골반의 방향 불일치. **현 tilt 데이터 (shoulder_tilt vs hip_tilt 의 차이)** 로 measurable. → **Phase 9 / Phase 11 의 ForceDirectionPattern 또는 GeometricCriterion 에서 활용**.

### 3.2 의미 ② — Body line 의 시각적 깨짐 (정성)
어깨-골반-무릎 의 align 이 의도된 line 에서 벗어나 보이는 현상. IPSF 에서 "Rounded shoulders" / "lack of extension" 로 deduction. **거리 metric 으로 측정 불가** — 관절 각도 (extension) 와 자세 (posture) 가 측정 대상. → **Phase 9 / Phase 11 의 LineCriterion 으로 이관**.

### 3.3 의미 ③ — 기술 조건부 폴-신체 관계 위반 (정량)
"동작 X 는 폴과 90° 각도를 이뤄야 하는데 한국 학생이 50° 로 수행 중" 형태. **기술 인식 후** (어떤 동작인지 식별 후) 그 동작의 Criteria 와 비교. → **Phase 11 의 Gemini 기술 인식기 + GeometricCriterion 책임**. Phase 8.1 책임 아님.

**Phase 8 의 `compute_axis_deviation` 가 측정하려 했던 것**: 어느 의미도 정확히 박제하지 못함. global distance 는 ① ② ③ 어디에도 매핑 안 됨.

**추천: α-4.**

근거:
1. IPSF Code of Points 가 글로벌 distance metric 을 deduction 항목으로 정의하지 않음 (§2.1, §2.4).
2. tilt 데이터는 origin-invariant, 정은지 baseline 자연스러움 (§1.3), Phase 9 1차 신호로 사용 가능 (PHASE8-INHERITED-ISSUES §3.2).
3. "기술 조건부 distance" 가 정말 필요하면 Phase 11 의 GeometricCriterion 으로 이관 — 본 phase 가 책임질 일 아님.
4. schema 변경 최소 — 필드를 deprecated / unavailable 고정으로 박제하고 3-way lockstep 동행.

### 4.2 Threshold calibration 방향 (β 옵션)

α-4 채택 가정 — β 는 **tilt** 임계값에 적용. distance 차원은 제거되므로 distance threshold 는 무관.

| 옵션 | 도메인 정합 | [[analysis-objectivity-no-human-scores]] 정합 | 비고 |
|------|------------|----------------------------------------------|------|
| **β-1** 정은지 5영상 sweep tilt distribution 의 median + N×stddev | △ 5영상 = 작은 sample, fragile. 하지만 임계값 calibration 은 데이터 분포로 가능 | ⚠️ 라벨링 (점수 ground truth) ≠ calibration (수치 분포). 정은지 분포 = "elite 선수의 자연 동작 범위" 박제 → severity='low' 영역 정의 = OK. memory invariant 정합 | distance 가 아닌 tilt 에 적용 시 잘 작동 — 정은지 tilt 분포 10°~58° (rotation-only, 동작별 의미 보존). 정은지 = 폴 세계챔피언 = "동작 의미 보존되면서 tilt 가 가장 의도된 값" reference |
| **β-2** IPSF Code of Points 의 axis 채점 항목 매핑 | ❌ IPSF 가 글로벌 tilt threshold 정의 안 함 (§2.1) — 매핑 불가 | OK | IPSF 가 "Twist body position" 외에는 tilt 임계 없음. 매핑 source 부재. **단독 사용 불가.** |
| **β-3** β-1 + β-2 combo (IPSF 정성 카테고리 + 정은지 분포) | △ β-2 의 IPSF source 부재 부분 = 정은지 분포로 보완. 가장 정직 | OK | β-1 과 동일하게 정은지 분포 기반 calibration. β-2 부분이 약하지만 "분포 기반 + IPSF Twist 정의 참조" 로 박제 가능 |

**추천: β-1 (정은지 분포 기반 calibration).**

근거:
1. IPSF 가 글로벌 tilt 임계값 정의하지 않음 → β-2 단독 불가능.
2. β-1 은 [[analysis-objectivity-no-human-scores]] 정합. 정은지 분포 = "elite 선수의 자연 동작 범위" 박제이지 점수 라벨링이 아님. 임계 수치 calibration 은 OK (메모리 명시).

4. β-3 도 가능 — IPSF 의 정성 "Twist deduction" 정의를 source_ref 에 박제 + 정은지 분포로 정량 임계 — 가장 정직하지만 β-1 대비 추가 작업량.

## 6. 외부 AI Reviewer 5 핵심 질문 답안

### Q1. Phase 8 의 어떤 가정이 처음부터 깨졌는지 (lockstep 단계에서 잡혔어야 할 사안인지)

**답**: 두 가지 가정이 깨짐.

(a) **"pose_aligned 좌표계 = image_2d 와 동등한 normalized 0~1 단위"** — RTMW 가 `keypoints_2d` 미박제임을 plan 단계에서 검증하지 않음. B' fix path (pole_aligned 3D fallback) 가 in-line sweep-driven 으로 추가되면서 단위 가정이 자동 mismatch.

(b) **"global pelvis distance 가 axis 차원의 정합 metric"** — IPSF Code of Points 에 global distance 임계 항목이 없음을 research 단계에서 확인하지 않음. polestyle-지식.md 의 "신체 라인" / "Rounded shoulders" deduction 을 distance metric 으로 잘못 추상화.

**Lockstep 단계에서 잡혔어야 했나**: (a) 는 RTMW 의 `keypoints_2d` 출력 여부를 사전 sweep 으로 확인했어야 함 — Phase 8 plan 단계의 "input 가용성 audit" 미흡. (b) 는 더 큰 design 문제이고 plan-checker 도 잡지 못했음. 본 research 가 IPSF NotebookLM lookup 으로 처음 박제한 결론.

### Q2. 좌표계 fix (α-1 ~ α-4) 중 어느 옵션이 폴스포츠 도메인 + Phase 9/10 입력 정합성 관점에서 최적인지

근거:

- Phase 9 는 tilt 만 받아도 ForceDirectionPattern 추론 가능 (PHASE8-INHERITED-ISSUES §3.2).
- Phase 10 (부상 위험 신호) 는 좌우 비대칭 / 요추 과신전 신호 — tilt 의 좌우 차이 (shoulder vs hip) 가 직접 활용 가능.

### Q3. Threshold calibration (β-1 ~ β-3) 중 어느 접근이 [[analysis-objectivity-no-human-scores]] memory invariant 와 정합인지

**답**: **β-1 (정은지 5영상 분포 기반 calibration)** 정합. β-3 도 정합 (β-1 + IPSF Twist source_ref).

### Q4. tilt-only 로 Phase 9 평행 진입 가능한지, 또는 distance 차원 박제 후 진입해야 하는지
