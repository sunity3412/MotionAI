<objective>
Slice 2: add the D-05 joint-hyperextension flag — belle's stated Mode-3 priority ("내 자세가 이러면 부상 위험 높다"). This is the phase's single genuinely novel algorithm: distinguish normal flexion from reverse-bend (genu recurvatum / elbow hyperextension) by tracking the **cross-product sign in the segment-local sagittal plane**, because dot-product gives only direction-blind 0–180° magnitude. Knee and elbow are 1-DOF hinges, so this is valid.

Codex flagged D-05 as the highest-risk part (sign convention fragile under inversion/spin; the firing function may not receive a reference frame; synthetic-only tests can pass while real elite keypoints misclassify). This plan hardens all three: the sagittal reference is constructed INTERNALLY from the already-pole-aligned `keypoints_4ch` (so no external frame is needed and the locked signature is sufficient); the algorithm fails CONSERVATIVE (no flag) whenever geometry/confidence is ambiguous; and a REAL elite-keypoint regression (정은지 reference angles → zero hyperextension flags) is added alongside the synthetic tests.

The flag is absolute-signal (both modes), fires via the D-02 LOCAL+TEMPORAL AND-gate with joint-localized control-loss (`unstable_body_parts` containing the specific knee/elbow key), and auto-renders through the `InjuryRiskSection` already built in 10-02. Absolute detection floors come from external clinical literature (knee >5° genu recurvatum; elbow >10° Beighton) tagged [CITED], severity bands at 10°/20° — NOT curve-fit to the 13 videos (D-07 / Pitfall 3).

Purpose: deliver the Mode-3 core risk signal with calibrated, literature-sourced, conservatively-gated direction detection validated against real elite keypoints.
Output: D-05 firing rule in safety_flags.py; hyperextension tests (synthetic + ambiguous + real-elite) GREEN; auto-rendered flag.
</objective>
