Python frozen dataclass + TS interface + docs/contract.md §9.12 세 곳 모두 동일 shape:

**필드 10개** (R10 정합 — warnings 포함 + R2 정합 — axisData 별도 field + R7 iter-2 — axisMask boolean[T×3] 신설, NaN sentinel 제거):
- `version: str` (non-empty, "1.0" 초기)
- `joints: list[str]` (len = J = 8 body keypoints, default = 8 KeypointName tuple — **R11 정합: axis 는 별도 axisData**)
- `frames: int` (>= 0)
- `fps: float` (> 0, **R3 정합 — required, default 제거**)
- `data: list[float]` (flat, length = T × J × 2 — 검증 __post_init__)
- `confidence: list[float]` (flat, length = T × J — visibility source per R6, `clamp(Keypoint2D.visibility, 0, 1)`)
- `reliability: list[str]` (length = T, 각 element ∈ {"high","medium","low"})
- `axis_data: list[float]` (Python snake_case per R6 iter-2; Firestore/TS 변환 = `axisData` via `_dataclass_to_camel_case_dict`) — **R2 신설** flat, length = T × P × 2, P=3 polyline points (shoulder_mid, hip_mid, knee_mid). **R7 iter-2 정합 — 모든 좌표는 finite float (NaN 0회)**. knee_mid 가 미가용일 때는 `(0.0, 0.0)` placeholder + `axis_mask` 가 false 박제 → UI 가 mask 참조해서 2-point 만 렌더.
- `axis_mask: list[bool]` (Python snake_case; Firestore/TS = `axisMask`) — **R7 iter-2 신설** flat, length = T × 3 (shoulder/hip/knee). 각 point 의 가용성. shoulder/hip 은 거의 항상 True, knee 만 false 가능. UI 는 mask 가 false 인 point 를 skip 하고 polyline 그림.
