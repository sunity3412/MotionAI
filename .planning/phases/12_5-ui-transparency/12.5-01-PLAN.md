- **정수 weightPercent (Largest Remainder Method)**:
  ```python
  N = len(dims)
  if N == 0: return {}
  base = 100 // N             # 3 → 33, 2 → 50, 1 → 100
  remainder = 100 - base * N  # 3 → 1, 2 → 0, 1 → 0
  # 첫 remainder 차원에 +1 (안정적 순서: dimension_scores 키 순)
  weights_pct = {dim: base + (1 if i < remainder else 0) for i, dim in enumerate(dims)}
  # 검증: sum(weights_pct.values()) == 100
  ```
- **baseline (mode-aware)**:
  - mode1: `angle`="정은지 측정값 + IPSF 실행 기준 참고", `line`="정은지 측정값 + 신전 완성도 (IPSF 실행 기준 참고)", `stability`="hold 구간 떨림 (절대 지표)"
