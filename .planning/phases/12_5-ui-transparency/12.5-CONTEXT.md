## 4. Phase Scope (in/out)

### IN scope

1. **backend `dimensions.py` 신 helpers + `assemble.py:build_result` 가 `comparison["mode"]` 기반 + 산식-정합 `dimensionExplanation` 출력** (Codex v2 HIGH-1/2/3 반영)
   - 구조: `Record<ScoreDimension, { weightPercent: int; baseline: string; deficitSummary: string }>`
   - **`weightPercent`** (정수, Largest Remainder Method, 합 = 100):
     - 3차원 → `[34, 33, 33]`
     - 2차원 → `[50, 50]`
     - 1차원 (mode3 first 가 line=None 시 stability 만) → `[100]`
   - **`baseline`** (mode 박제 = `comparison["mode"]` 에서 직접 박제, 별도 mode 인자 X):
     - mode1 angle = "정은지 측정값 + IPSF 실행 기준 참고"
     - mode1 line = "정은지 측정값 + 신전 완성도 (IPSF 실행 기준 참고)"
     - mode1/mode3 stability = "hold 구간 떨림 (절대 지표)"
     - mode3 line = "IPSF 신전 완성도 (절대 지표)"
     - mode3 second+ angle = "이전 영상 대비 관절 각도 일관성"
   - **`deficitSummary`** (점수 산식과 동일 source — Codex v2 HIGH-1/2 fix):
     - `angle` → `kismam.top_issues(assessments, n=1)[0]` worst joint
     - `line` → `dimensions.line_deficits_by_joint(joint_angles, profile)` worst — `profile.expects_extension(k)` 박제 관절만
     - `stability` → `dimensions.stability_wobble_by_joint(joint_angles, hold_window)` worst — `_STABILITY_TOL_DEG=15` 산식 정합
   - 양호 임계 = 차원 점수 ≥ 80 시 양호 카피 (수치 박제 X)
