motion from the already-stored S3 video and threads the live pose_frames/angles through the SAME
`sunity_shared.analysis` functions the student `_process` calls (D-01 동일 코드 1벌) to produce all four

markdown (SC#3) ships alongside. This makes Plan 14-01's RED parity test GREEN.

visually-verified active joints3d/angles.
