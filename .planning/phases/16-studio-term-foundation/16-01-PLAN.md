## Goal

- NotebookLM lookup 으로 데이터 이미 확보 — 박제만 하면 됨 (belle/강사 협업 불필요)

## Tasks

### T-1: AKA 매핑 13개 데이터 파일 박제

**산출물**: `backend/data/aka-mapping.json` (또는 동등 위치)

**내용**: 13개 entry × 다음 필드:
- `studioName` — 한국 학원 통용명 (예: "나비")
- `studioNameAliases` — 다른 표기 (예: ["나비 자세", "Butterfly", "버터플라이"])
- `ipsfCode` — IPSF Element Code (예: "F401" / "F402")
- `ipsfOfficialName` — IPSF 공식 영문명 (예: "Inverted Torso Hook")
- `category` — IPSF 카테고리 (예: "Flexibility")
- `sourceRef` — NotebookLM citation (예: "IPSF Pole Sports CoP 2025-2027 Page 197 Taxonomy / NotebookLM lookup 2026-06-02 notebook 96b061e8-bb7c-41c5-8606-8ceef2ce1aa3")
- `isRegistered` — true (분기 1 = AKA 매핑됨)

**13개 동작** (memory [[studio-term-3branch-system]] 박제 그대로):
나비 / 큐피드 / 데드리프트 / 아이샤 / 제이드 스플릿 / 제미니 / 스콜피오 / 숄더 마운트 / 펜실 홀드 / 아이언 엑스 / 테디 / 플랫라인 / 요기니

**검증**: JSON schema 검증, 13개 entry 모두 필드 완전성, sourceRef 모두 NotebookLM 인용 포함

### T-4: 분기 3 자동 수집 데이터 스키마 정의

**산출물**: Firestore 컬렉션 스키마 문서 (예: `.planning/phases/16-studio-term-foundation/16-AUTOCOLLECT-SCHEMA.md`)

