> ⚠️ **iter6/iter7 HIGH-1 — sensitivity ASSET lock before derivation:** policy freeze 만으론 부족하다 — cap derivation 의 실제 입력은 `derive_caps.py` 가 소비하는 `sensitivity.yaml` 의 `video_key` 다. 그래서 `eval_manifest_assets.lock.json` 은 `{eval_manifest_sha256_pre_derivation, sensitivity_manifest_sha256_pre_derivation, policy_sha256, sensitivity_keys[]}` 로 **eval_manifest AND sensitivity.yaml 둘 다** 해시하고 CROSS-FILE invariant(eval_manifest.source.key==sensitivity.yaml.video_key + 1:1 + bucket/direction 일치)를 강제한다. derive_caps 는 assets lock 부재/두 파일 중 하나라도 drift/두 파일 disagree 시 실행 거부. `--phase-gate` 는 `eval_manifest_assets_sha256_pre_derivation` AND `sensitivity_manifest_sha256_pre_derivation` drift 시 FAIL.
> ⚠️ **iter7 HIGH-2 — freeze CREATE/VERIFY 분리:** lock 파일 CREATE 는 별도 auditable step `freeze_eval_manifest.py`(subcommand `policy`=첫 scored sweep 전, `assets`=derivation 전)가 하고, `derive_caps.py` / `--phase-gate` 는 lock 을 **읽어 VERIFY 만** 한다 — derive 가 pre-sweep/pre-derivation hash 를 만드는 경로는 제거됐다(sweep 출력 본 뒤 "pre-sweep" 해시 생성 = 원래 버그).

## Sampling Rate

- **After every task commit:** `cd backend && PYTHONPATH=shared/python python -m pytest tests/ -q`(해당 모듈은 `-k` 로 좁힘) + 객관성 내성검사(build_schema/dataclass — 점수 필드 0) + (result.tsx 변경 시) `cd app && node scripts/assert-result-score-suppression.mjs --self-test && node scripts/assert-result-score-suppression.mjs`
- **After every plan wave:** `cd backend && PYTHONPATH=shared/python python -m pytest tests/ -q`(전체 회귀 0) + `cd backend && PYTHONPATH=shared/python python evals/phase20/assert_baseline_v2.py --self-check` PASS(approval 아님) + fail-closed pytest GREEN + 정적 억제 단언(self-test + 실행) exit 0
- **Before `/gsd-verify-work`:** pod-free suite green + 정적 억제 단언(self-test + 실행) exit 0 + (Pod 재개 시) `cd backend && PYTHONPATH=shared/python python evals/phase20/assert_baseline_v2.py --phase-gate` PASS ↔ baseline 대조 + manifest-sourced per-row status counts + locked-policy/full-manifest/asset hash report
- **Max feedback latency:** ~60s (pod-free)

> 모든 backend 커맨드는 `cd backend && PYTHONPATH=shared/python ...` 단일 shape(iter5 MEDIUM-1) — repo-root pytest/PYTHONPATH 누락 금지.
