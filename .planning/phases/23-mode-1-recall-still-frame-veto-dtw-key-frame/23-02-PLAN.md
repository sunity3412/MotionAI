관절각은 스케일 무관 3D 각도로 **직접 수치**("무릎 145° vs 정은지 178°, 33° 더 굽음") —

user_frame_idx/ref_frame_idx)에서만 계산한다(D-10 HIGH-3 — DTW median 을 still 프레임의
정확 각도로 표기하면 안 됨). DTW median(`per_joint_deviation`)은 **기존 scoring 경로**로
분리 유지하고, robustness 목적으로 window median 을 surface 할 경우 `windowMedianAngleDeltas`
(+sourceFrameIndices/windowPolicy)로 별도 명명한다. 거리는 절대 cm 금지·**몸-상대 칸/층** —
칸 수치는 **keypoint + 폴축/바닥/엉덩이-라인 baseline 에서 결정적 기하 계산**으로 코드가
산출한다(Gemini 가 칸을 지어내지 않음, D-08 H2). **percent("100%") 표기 절대 금지**
(`_SCORE_PATTERN` 누수 — 정상 verdict 폐기 위험). (2) 원인: Gemini 가 결함군을 보고 가능한
root cause(힘 부족/폴 밀착 풀림)를 기존 dual-coach "원인" 섹션에서 **"~로 보임" 가설**로
