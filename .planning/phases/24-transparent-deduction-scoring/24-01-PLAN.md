<objective>
Build the pure, numpy-only transparent deduction-tally engine that REPLACES the severity→fixed-ceiling band. The engine consumes the Phase 23 quantification substrate (already-computed angle deltas + body-relative notches) plus an IPSF criterion-grouping table, and emits a `DeductionBreakdown`: `final = max(0, 100 − Σ(per-criterion capped deduction))`, with a full per-criterion record list (measured value, baseline, deviation, applied rule id, −points, IPSF anchor citation). This plan delivers the engine, its grouping/weight table, the 3-way contract for persistence, and the unit gates — all pure (no Pod, no Gemini, no AWS). The pipeline seam wiring (Plan 02) and eval gates (Plan 03) build on this.

Purpose: belle rejected severity→fixed band as human judgment injected per-video (ND-01, [[scoring-must-be-transparent-deduction-tally]]). The point is a tally whose every −point is traceable to a named measured deviation + a named rule, identical rule across all videos (no curve-fit). This engine is that tally.

Output: `deduction_engine.py` + `ipsf_criteria.py` (pure core), `DEDUCTION_*_KEYS` in `models.py` + `DeductionBreakdown` in `analysis.ts` + `docs/contract.md §10` (3-way lockstep), and `test_deduction_engine.py` (Wave 0 unit gates SCORE-10..16 partial).
</objective>
