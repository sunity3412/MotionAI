<objective>
Build the pure, numpy-only transparent deduction-tally engine that REPLACES the severity→fixed-ceiling band. The engine consumes the MEASURED GEOMETRY LAYER (the dimension/kismam deviations that today produce `score_result["overallScore"]` via `assemble.py:736` / `kismam.overall_score`) PLUS the Phase 23 quantification substrate (angle deltas + body-relative notches) and an IPSF criterion-grouping table. It emits a `DeductionBreakdown` OBJECT (`{baseline, records, final, coverageGaps, fallback}`): `final = max(0, round(100 + Σ(record.points)))` where each `record.points` is SIGNED NEGATIVE, with a full per-criterion record list (measured value, baseline, deviation, applied rule id, signed-negative points, IPSF anchor citation). Gemini severity is used ONLY to LOCATE which criterion is implicated and to ADD vision-only faults — it never gates whether a measured deviation deducts. This plan delivers the engine, its grouping/weight table (scoped to what the substrate can actually measure, with deferred gaps TRACKED not hidden), the 3-way contract for persistence, and the unit gates — all pure (no Pod, no Gemini, no AWS). The pipeline seam wiring (Plan 02) and eval gates (Plan 03) build on this.

Purpose: belle rejected severity→fixed band as human judgment injected per-video (ND-01, [[scoring-must-be-transparent-deduction-tally]]). The point is a tally whose every −point is traceable to a named measured deviation + a named rule, identical rule across all videos (no curve-fit). Per ND-03 the tolerance/penalty must expand to ALL dimensions feeding the tally — so the measured geometry layer (not a 100-minus-Gemini-only recompute) is the substrate, preserving Phase 20's false-positive purpose: a fault video must NOT score 100 just because Gemini stayed silent or the reference pair was missing.

Substrate-honesty scope (ND-06): the `line`/extension criteria (`line`, `leg_extension`) derive their deviation from `dimensions.line_score` / `extension_deviation`, which gate on `profile.expects_extension(joint)`. For a move whose technique profile has an EMPTY `joint_expectations` ({} — unregistered/미상/low-confidence moves), `expects_extension` returns False for every joint, so `line_score` returns None and that criterion contributes 0 deviation (and 0 deduction). This is CORRECT and HONEST — a true 0, NOT a silent band and NOT a false penalty. The unregistered/unknown-fault case is defended by the measured `dimension_overall` fallback + the Gemini-located criteria, NOT by a `line` deduction the substrate cannot produce. The plan does not over-claim `line` coverage for unregistered moves; it claims the 0-contribution is honest.

Baseline-as-scoring-substrate (ND-05, HIGH-4): the per-move `baseline_kind` (floor/pole_vertical/hip_line) is a GENUINE scoring substrate, not an audit label — the `body_relative_reach` criterion (the one `reference_relative` criterion) consumes `bodyRelativeNotches.delta_notches`, which `vision_veto.body_relative_notches` computes baseline-relative. Different baseline_kind → different notch reach → different measured deviation → different score. This criterion activates ONLY for hand/knee reach faults (the measurable `_NOTCH_REACH_KEYPOINTS`); grip/head/torso stay coverage gaps (not force-mapped).

Output: `deduction_engine.py` + `ipsf_criteria.py` (pure core), `DEDUCTION_*_KEYS` in `models.py` + `DeductionBreakdown` in `analysis.ts` + `docs/contract.md §10` (3-way lockstep), and `test_deduction_engine.py` (Wave 0 unit gates SCORE-10..16 partial).
</objective>
