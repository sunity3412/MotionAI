<objective>
Build the pure, numpy-only transparent deduction-tally engine that REPLACES the severity→fixed-ceiling band. The engine consumes the MEASURED GEOMETRY LAYER (the dimension/kismam deviations that today produce `score_result["overallScore"]` via `assemble.py:736` / `kismam.overall_score`) PLUS the Phase 23 quantification substrate (angle deltas + body-relative notches) and an IPSF criterion-grouping table. It emits a `DeductionBreakdown`: `final = max(0, 100 − Σ(per-criterion capped deduction))`, with a full per-criterion record list (measured value, baseline, deviation, applied rule id, −points, IPSF anchor citation). Gemini severity is used ONLY to LOCATE which criterion is implicated and to ADD vision-only faults — it never gates whether a measured deviation deducts. This plan delivers the engine, its grouping/weight table (scoped to what the substrate can actually measure, with deferred gaps TRACKED not hidden), the 3-way contract for persistence, and the unit gates — all pure (no Pod, no Gemini, no AWS). The pipeline seam wiring (Plan 02) and eval gates (Plan 03) build on this.

Purpose: belle rejected severity→fixed band as human judgment injected per-video (ND-01, [[scoring-must-be-transparent-deduction-tally]]). The point is a tally whose every −point is traceable to a named measured deviation + a named rule, identical rule across all videos (no curve-fit). Per ND-03 the tolerance/penalty must expand to ALL dimensions feeding the tally — so the measured geometry layer (not a 100-minus-Gemini-only recompute) is the substrate, preserving Phase 20's false-positive purpose: a fault video must NOT score 100 just because Gemini stayed silent or the reference pair was missing.

Output: `deduction_engine.py` + `ipsf_criteria.py` (pure core), `DEDUCTION_*_KEYS` in `models.py` + `DeductionBreakdown` in `analysis.ts` + `docs/contract.md §10` (3-way lockstep), and `test_deduction_engine.py` (Wave 0 unit gates SCORE-10..16 partial).
</objective>
