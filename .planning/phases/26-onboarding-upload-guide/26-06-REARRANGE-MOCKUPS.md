## 최악 데이터 케이스 (worst-data-case) — 반드시 확인

**단계 2 소스 선택 화면에, 긴 모션명 + 에러 + 권한 안내가 동시에 뜬 상태 (비-스크롤 View):**

```
┌─────────────────────────────┐
│  ‹                          │
│  어떻게 영상을               │
│  가져올까요?                 │
│  elbow-twist-sister ·       │  sub (긴 모션명 modeContext, 2줄로 래핑)
│  정은지 선수와 비교           │
│  ┌───────────────────────┐  │
│  │ 📹 즉석 촬영            │  │
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ 🖼 앨범에서 선택         │  │
│  └───────────────────────┘  │
│  가장 정확한 분석을 위해 앱에서 │  guidance #1 (3줄)
│  직접 촬영하거나 원본 화질…    │
│  카톡 등으로 받은 영상은…      │
│  몸 전체가 화면에 잘 들어오는   │  guidance #2 (2줄)
│  거리(약 2~3m)에서 촬영…      │
│  영상은 분석에만 사용하고…      │  privacyNote
│  ☐ 분석 영상을 AI 개선(학습)에 │  opt-in 행
│    활용하는 데 동의해요 (선택) │
│  mp4, mov 형식의 영상만…      │  error (틸)
│  설정에서 권한 허용하기         │  permission 링크
└─────────────────────────────┘
  ⚠ 소형 기기(SE 등)에서 하단 opt-in/error/permission 이 화면 밖으로
     밀릴 수 있음 — 현행은 ScrollView 아님. 이 케이스가 재배치 판단 근거.
```

**카톡 경고 다이얼로그(최악: 위 화면 위에 모달 오버레이):** brandBg 틴트 카드 + 빨간 느낌표 + 가로 2버튼([이대로 계속] / [다른 영상 선택]) — 이 다이얼로그 자체는 재배치 대상 아님(D-06 불변), 배경 화면 밀도만 이슈.

**FAQ 전체 펼침(help.tsx worst-case):** 6개 아코디언 전부 expand + 튜토리얼 링크 = 세로로 길지만 ScrollView라 안전(밀도 이슈 없음).

### Ⓐ 안내 밀도 분산 (proposal-a) — source-select 정리, 로직 0 변경

3. 프라이버시 1줄 + opt-in 행은 **pick 직전 위치 유지**(D-08/D-09 — 동의는 pick 직전 필수, 이동 금지).

```
┌─────────────────────────────┐
│  ‹  어떻게 영상을 가져올까요?  │
│  정은지 선수 동작과 비교       │
│  [📹 즉석 촬영]              │
│  [🖼 앨범에서 선택]           │

│  거리(약 2~3m)에서 촬영해요.   │
│  영상은 분석에만 사용…         │  privacy (유지)
```

- **장점:** 카드 아래 블록 4→3(캡션 2→1)로 시각 밀도 완화 + 스크롤로 오버플로 근본 차단. 동의/게이트 로직 무접촉(위치 유지, 캡션만 병합).

- **SCENARIO 정합:** 0.5/1/1.5 위치 전부 유지, 1·1.5 안내를 1블록으로 압축(가독성↑). 재배치라기보다 "정리".
