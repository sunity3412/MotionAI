### 결정
1. **섹션 순서 = 10항 순서안 승인.** 요약 카드 → 위험 결함(있을 때만) → 오늘 고칠 것 top-1 → 동작 비교 → 나머지 감점(접힘) → 성장·지난 미션 → 보완 운동 → 강사 질문 → 심사 정보 코너 → 참고하세요(31). 근거 = Shneiderman overview-first + 위험 트리아지(Kaia) + 31 D-09 invariant(참고코너는 채점 표면 전부 뒤).
2. **방향 = 세로 스크롤(안 V).** 가로 카드 넘김(안 H) 폐기 — 흐름 연속·위→아래 트리아지 자연·안전 카드 건너뜀 위험 없음.
3. **belle 조건 병기 (★후속에 반드시 전달):** belle 원문 *"폰트랑 세부 조절은 세부적으로 잡을 것"* — 순서·방향은 확정이나 **폰트·세부 간격은 확정 아님, 후속에서 세부 조정.** 오케스트레이터 약속 = 32-07(토큰)·32-11(배선)·32-12(전 화면 점검)에서 세부 조정.

### 정직 프레임 (유지)
번역 레이어의 1차 정당화 = **이해 가능성**(191° 구조적 불가독). 외부 큐 학습효과는 원문헌 유리하나 출판 편향 보정 후 축소(McKay 2025) — 과장 금지. 수치 삭제 금지(계층화만).

### D-10 게임 프레임 적용 범위 = 안 B (감점 카드 + 성장 탭)
- 확정 3요소(목표 게이지 바 + 오늘의 미션 + mode3 기록 갱신 배지)를 감점 카드에 + **성장 섹션에 미션 추적(연속 개선/목표 도달 카운트)**. 전면 확장(안 C)·추가 아이디어(목표 근접 링 등)는 **미채택.**
- **★belle 강한 교정 — 수치 전면 금지 (D-09 재확인·강화):** 목업 ②탭이 무릎 각도 수치를 게이지에 크게 배치한 것에 belle 반발. 원문 *"왜 자꾸 무릎각도를 둬 다르게 표현하자니깐"*. 확정 규칙:
  - 사용자 **측정 수치(각도)는 절대 전면/헤드라인 금지** — "이렇게 분석되었다" **근거 표기로만**.
  - **게이지도 각도 숫자 확대 금지** — 목표까지 남은 정도를 **길이(bar)로만** 표현.
  - **②탭 목업의 각도 전면 배치 = 폐기** (목업은 canon 아님 — 시각 원형은 아래 ⑤).

### D-03 참고 지표 = 재설계 (개인화 심사 시뮬레이션) — 기존 2형태 모두 폐기
- **기존 두 형태(독립 심사 코너 / 감점 카드 흡수) 모두 "지식전달형"으로 비판·폐기.** belle 원문: *"내 자세에서 심사였다면 이렇게 평가했을 거라는게 중점이 되어야 하는데 그냥 심사 기준만 말하는 지식전달형 같음"*.
- **재설계 확정 = 개인화 심사 시뮬레이션:** "내 수행이 실제 심사였다면 이렇게 평가받았을 것" — 사용자의 **실제 결함들에 IPSF 감점 규칙을 적용해** 보여줌(투명 감점 합산 — 회당 −0.2/−0.5 등 **실존 규칙 곱셈**, **자의적 % 환산 아님** → D-09 % 금지와 무충돌).
- 배치 = **독립 코너 하나, 채점 표면 뒤**(참고하세요(31)보다 위, 순서 #9 자리).
- 소비처: **32-11**.

### ⑤ 참조 원형 채택 (신규 — belle Figma 과거 결함 상세 시트) — 32-10 시각 원형
belle이 Figma에서 과거 제작 결함 상세 시트 구성을 가져와 채택 (원문 *"이 양식 반영하면 각도도 적게 표현하면서 좋을 것"*). **32-10 드릴다운 시트·감점 카드 재구성의 시각 원형:**
- 상단: **단계 배지**(예 RELEASE) + **부위 칩**(예 몸 중심) + 우상단 **"신뢰도 높음"**
- 헤드라인: **수치 0의 문구 문장** (예: "정은지 선수 기준 패턴과 비교했을 때, 몸 중심이 옆으로 기울며 중심 잡는 힘이 약해지는 모습이 보여요.")
- **결함 프레임 확대쌍 (★belle 후속 확인):** **내 영상 crop vs 정은지 선수 crop 페어 사진 쌍**이 시트 구성에 포함. 동선 = **점수 계산 내역에서 감점 항목 탭 → 드릴다운 시트에 [사진 쌍 + 문구 3단 + 측정 근거 박스] 함께 표시.** 감점 카드 본체에도 **인라인 줌 쌍** 포함(D-08/D-20). belle 질문 *"점수 누르면 확대사진 거기서 보여주기로 한 거 아니었나"* — D-17 자세 비교 카드 존치 결정과 정합(사진 쌍은 필수 렌더).
- 강사 연결 줄: "강사가 함께 보면 더 구체적 피드백을 받을 수 있어요"
- **회색 근거 박스 "이 원인은 어떻게 측정됐나": 수치는 여기에만** (예: "lock 단계에서 어깨 기울기가 25° 측정됐어요. IPSF 폴스포츠 기준 = 20° 이내.")
- 불릿 2: "관련 부위 — 몸 중심 (코어 안정)" / "확인하기 — 거울 보며 동작 직접 재현"
- 하단 고지 박스: "AI가 추정한 가능성이에요. 강사 수업과 함께 확인하면 가장 정확한 피드백을 받을 수 있어요."
- **승인 문구집 3단(상태→왜→행동+코치 질문)이 이 껍데기에 매핑.**
- 소비처: **32-10**.
