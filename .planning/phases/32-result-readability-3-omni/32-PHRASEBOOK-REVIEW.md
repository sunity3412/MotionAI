## 1. 대표 카드 목업 (감 잡기용 — 실제 감점 카드에서 읽히는 형태)

### 다리 신전(펴짐) 부족

> **무릎이 기준보다 덜 펴져 있어요**  
> 다리 라인이 끝까지 뻗지 않으면 심사에서 신전 완성도로 감점되는 부분이에요  
> 👉 발끝으로 천장을 길게 밀어낸다는 느낌으로 다리를 쭉 뻗어보세요  
> 🗣 강사님께: “무릎을 끝까지 펴려면 어디에 힘을 줘야 하는지 강사님께 여쭤보고 싶어요”  
> 🏋 보완 운동: 다리 신전 운동군 — 무릎을 끝까지 펴는 다리 신전 근력이 받쳐줘야 하기 때문이에요

### 스플릿(다리 벌림) 부족

> **다리를 벌린 각도가 기준보다 좁아요**  
> 다리를 더 벌리지 못하면 스플릿 완성도에서 감점되는 부분이에요  
> 👉 양 무릎을 각각 반대쪽 벽으로 밀어낸다는 느낌으로 다리를 벌려보세요  
> 🗣 강사님께: “다리를 더 벌리려면 어떤 스트레칭부터 하면 좋을지 강사님께 여쭤보고 싶어요”  
> 🏋 보완 운동: 고관절·햄스트링 유연성 운동군 — 다리를 더 벌리려면 고관절과 햄스트링 유연성이 받쳐줘야 하기 때문이에요

### 왼쪽 무릎 각도(기준 대비)

> **왼쪽 무릎 각도가 기준 자세와 차이가 있어요**  
> 무릎 각도가 기준에서 벗어나면 자세 정확도에서 감점되는 부분이에요  
> 👉 왼쪽 무릎을 기준 자세의 무릎 라인에 나란히 겹쳐본다는 느낌으로 맞춰보세요  
> 🗣 강사님께: “왼쪽 무릎 각도를 기준에 맞추려면 어떻게 힘을 줘야 하는지 강사님께 여쭤보고 싶어요”  
> 🏋 보완 운동: 다리 신전 운동군 — 무릎 각도를 기준에 맞추려면 다리 신전 근력이 받쳐줘야 하기 때문이에요

### 무릎·팔꿈치 과신전 (위험 — 게임 프레임 없음, D-14)

> ⚠ **무릎이나 팔꿈치가 뒤로 꺾이는 방향까지 펴져 있어요**  
> 관절이 중립을 넘어 뒤로 꺾이면 인대에 무리가 갈 수 있어요  
> 🗣 강사님께: “관절을 어느 정도까지 펴야 안전한지 강사님과 이 화면을 함께 확인해보고 싶어요”

### fail-closed (미지원 조합 — 행동문·운동 없음)

> **심사 기준과 차이가 측정된 부분이에요**  
> 기준과 차이가 있는 건 확인됐지만, 정확한 원인은 이 영상만으로 단정하기 어려운 부분이에요  
> 🗣 강사님께: “이 부분을 어떻게 고치면 좋을지 강사님과 이 화면을 함께 확인해보고 싶어요”

dimension_overall_fallback(엔진이 결함을 특정 관절로 국소화 실패) + entry 부재/미래 criterion 이 이 폴백을 탄다. **행동문·보완운동 없음** — whyLine 은 안전한 사실만, 코치 질문으로 강사 확인 유도.

- **상태:** 심사 기준과 차이가 측정된 부분이에요
- **왜:** 기준과 차이가 있는 건 확인됐지만, 정확한 원인은 이 영상만으로 단정하기 어려운 부분이에요
- **코치 질문:** 이 부분을 어떻게 고치면 좋을지 강사님과 이 화면을 함께 확인해보고 싶어요

## 6. 커버리지 매트릭스 요약 (개수 아닌 매트릭스가 커버리지 증명)

- **행:** 등록 10동작 + 미등재 = 11행 (ref-climb, ref-foxtop, ref-foxtop-split, ref-invert, ref-sideway-spin, ref-kip-up, ref-power-spin, ref-peter-pan, ref-elbow-twist-sister, ref-pdshape, 미등재)
- **열:** criterion 14 + safetyFlags 4 = 18열
- **셀:** 11행 × 18열 = 198 셀 — 전부 분류, 빈 셀 0

| 열(criterion) | 분류 |
|---|---|
| `leg_extension` | criterion_common |
| `arm_extension` | criterion_common |
| `split_angle` | criterion_common |
| `line` | criterion_common |
| `body_relative_reach` | criterion_common |
| `angle_vs_reference__left_elbow` | criterion_common |
| `angle_vs_reference__right_elbow` | criterion_common |
| `angle_vs_reference__left_shoulder` | criterion_common |
| `angle_vs_reference__right_shoulder` | criterion_common |
| `angle_vs_reference__left_hip` | criterion_common |
| `angle_vs_reference__right_hip` | criterion_common |
| `angle_vs_reference__left_knee` | criterion_common |
| `angle_vs_reference__right_knee` | criterion_common |
| `dimension_overall_fallback` | fail_closed |
| `asymmetry` (safety) | safety_common |
| `trunk_hyperextension` (safety) | safety_common |
| `joint_hyperextension` (safety) | safety_common |
| `level_mismatch` (safety) | safety_common |

- **규칙:** 분류는 전 motion 행에 동일 적용된다 — entries 가 criterion-keyed(동작 독립)이라 등록 10동작·미등재 모두 같은 phrasing 경로를 탄다. 동작 전용(motion-specific) override 는 현재 0 (일반화 우선 — 같은 criterion 이 동작마다 다른 뜻이 되지 않음, [[scoring-redesign-must-generalize-no-overfit]]). 따라서 11행 × 18열 = 198 셀이 전부 {criterion_common | safety_common | fail_closed} 로 분류되며 빈 셀 0.
- **fail-closed 정책:** 미지원 조합(entry 부재 criterion, 미래/드리프트 id 포함)과 dimension_overall_fallback 은 failClosed 로 라우팅된다. failClosed 는 cueLine·exerciseId 를 만들지 않고(행동문 생략), whyLine 은 안전한 사실만, coachQuestion 으로 강사 확인을 유도한다 — 일반론 교정 지시 생성 경로 0 (D-11 일반론 금지).
