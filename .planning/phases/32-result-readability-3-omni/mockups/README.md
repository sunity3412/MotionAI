## 안별 1줄 요약

### ① 섹션 순서 (D-02) + 세로/가로
- **10항 순서안** — 요약1장 → 위험결함 → 오늘 고칠 것(top-1) → 동작 비교 → 나머지 감점(접힘) → 성장·미션 → 보완운동 → 강사 질문 → 심사 정보 코너 → 참고하세요(31 invariant). 근거는 각 행에 부착(Shneiderman/트리아지/31 D-09).
- **세로 스크롤(안 V)** — 흐름 연속·트리아지 자연·구현 최소. **[권장]**
- **가로 카드 넘김(안 H)** — 섹션당 카드 1장 집중도↑ 이나 순서 통제/안전 카드 건너뜀 위험.

### ② 게임 프레임 강도 (D-10) — 확정 3요소(게이지+미션+기록배지)는 A·B·C 공통, 범위만 다름
- **안 A** — 3요소를 top-1 감점 카드 '안에만'. 가장 보수적.
- **안 B** — A + 성장 섹션에 미션 추적(연속 개선/목표 도달 카운트). **[권장]** 루프가 성장 섹션에서 닫힘.
- **안 C** — 전면 확장(요약 카드 히어로 게이지) + Claude 추가안 3종(목표 근접 링 / 오늘의 한 가지 히어로 / 도달 축하 마이크로 배지 — 모두 측정 기반, 안전 결함 제외).

### ③ 최악·엣지 케이스 (선제시 원칙)
- **최악** — 감점 7 + 장문 측정 문구 + 안전 결함 동시. 안전은 게임 프레임 제외(D-14), 장문 배지는 wrap(잘림 방지).
- **감점 0** — 축하 + 잘한 점은 측정 근거(감점 0 차원)에서.
- **부분 실패** — "하반신만 쟀어요"(D-29) + 못 잰 것 코치 질문 자동 등재.
- **근거 빈약** — 없는 칭찬 금지(D-06), 응원 톤 정직 고지 후 바로 오늘 고칠 것.

### ④ 참고 지표 형태 (D-03) — 둘 다 IPSF 실존 수치 사용
- **형태 1** — 독립 '심사 정보 코너'(순서 #9, 채점 표면 뒤). **[권장]** 교육은 판정 뒤·감점 카드 과밀 방지.
- **형태 2** — 각 감점 카드의 '왜' 줄에 "실제 심사: 정렬 회당 −0.2" 한 줄로 흡수.

### ⑤ 강조 체계·타이포 (D-05)

## D-09 검사표 (판정 기준 명문화 — 전 목업 자체 점검, 리뷰 반영)

| 검사 항목 | 기준 | 목업 준수 |
|---|---|---|
| 측정 수치(각도·편차·점수)가 헤드라인/강조에 등장? | 금지 — 헤드라인은 '몸 말'만 | PASS — 모든 헤드라인 무수치, 각도는 `.mbadge`만 |
| 측정 수치 배지 개수 | 카드당 1곳(소형 보조) | PASS — `.mbadge` 카드당 1개 |
| % 환산 노출? | 금지(자의적 숫자 생성 방지) | PASS — % 일치/환산 0건, 게이지도 실측 단위(°) |
| 점수(overall) | 소형 배지만, 첫 화면 히어로 금지 | PASS — `.score-mini` 옥타곤 34px, 요약 카드 우측 보조 |
| **IPSF 규정 수치(회당 −0.2 등)** | **측정값 아님 → 본문 허용**(교육 콘텐츠) | 구분 적용 — `.ipsf`/심사 코너에만, `.mbadge`와 분리 |
| 참고코너(31) 위치 | 채점 표면 전부 뒤(invariant) | PASS — 순서 #10, 심사 코너(#9)보다도 뒤 |
| 안전 결함 게임화 | 금지(D-14) | PASS — 안전 카드에 게이지/미션/배지 미적용 |

**측정 수치 vs IPSF 규정 수치 구분(핵심):**
- **측정 수치** = 이 사용자 영상에서 **잰 값**(각도 141°, 편차 19°, 점수 62). → D-09 적용: 헤드라인 금지·배지 1곳·% 금지.
- **IPSF 규정 수치** = 심사 규정 **교육 값**(회당 −0.2, 회당 −0.5, 20° 허용 오차, 추락 −3.0 — `docs/research/폴스포츠-지식.md` 실존). 측정값이 아니므로 심사 정보 코너 본문에 허용.
- 전 목업이 이 구분을 지킴(측정값은 `.mbadge`, 규정값은 `.ipsf`).

## Figma 확인 결과 (기록 — Pitfall 11 준수)

- **결과 화면은 Figma에 미설계로 문서 확정.** `design.md §8`이 "❌ 분석 결과 화면"을 명시적 **미완성(미설계) 화면**으로 기재(line 437), §7 네비게이션도 "[미완성] 분석 결과 화면"(line 427). 즉 fileKey `jrdI7kp245HkPfLB0nclsz`에 결과 화면 프레임 **부재가 문서로 확정**됨 — 텍스트 검색(노드 이름 검색 무효, figma-search-by-text-not-node-name) 이전에 이미 문서 근거로 부재가 성립.
- **출발점 = 현행 구현** `app/src/app/analysis/result.tsx`(2745줄)가 사실상의 현 디자인. 목업은 이 현행 위에서 재배치(D-01/D-02) + 번역 레이어(D-08/D-09)를 얹은 형태.
- **라이브 Figma MCP 미호출 사유:** 본 executor 환경에 노출된 도구는 Read/Write/Edit/Bash뿐(에이전트 tools 제한 시 MCP 도구가 스트립되는 상류 버그). 결과 화면 부재는 위 문서 근거로 이미 authoritative하므로 라이브 조회 불필요. 필요 시 belle/오케스트레이터가 Figma MCP로 교차 확인 가능.
- **design.md 준수 확인:** 브랜드 `#FF4B33`(변경 없음)·Pretendard(CDN 링크+시스템 폴백)·라이트 전용(다크 배경 0, 안전 카드도 라이트 틸)·카드 radius 15pt·오류/안전 톤 `#54B8CD`(레드 금지) — §0 자율 설계 결정 트리 적용.
