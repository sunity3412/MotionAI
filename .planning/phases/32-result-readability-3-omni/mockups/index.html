② 게임 프레임 적용 범위 (D-10)

D-10 확정 3요소(목표 게이지 바 + 오늘의 미션 + mode3 기록 갱신 배지, 감점 카드 내)는 세 안 모두 공통 포함 — 미결은 적용 범위뿐. 톤 = "장난스럽진 않지만 친숙하게"(D-12). 아래 세 안은 동일 최악 fixture(감점 7 + 안전 결함)를 쓰고 확장 범위만 다르다. 수치는 헤드라인 금지·소형 배지 1곳(D-09).

안 A — 감점 카드 한정3요소를 top-1 감점 카드 '안에만'. 나머지 화면은 차분한 정보 톤. 가장 보수적.
안 B — + 성장 탭 확장감점 카드 3요소 + mode3 '성장·지난 미션' 섹션에 미션 추적 타임라인/연속 달성 표기까지.
권장: 안 B (미션→연습→확인 루프가 성장 섹션에서 닫힘 · 과함 없음)
안 C — 전면 확장 + 추가 아이디어요약 카드에 '오늘의 한 가지' 히어로 게이지까지 승격 + Claude 추가안 3종(아래).
Claude 추가 아이디어 제안 (D-10 원문 "추가 아이디어 제안" — 안 C에 반영, 채택은 belle):
① 목표 근접 링(Streak Ring) — 같은 미션을 연속으로 개선하면 게이지 옆 작은 링이 채워짐(측정 개선 기반, 포인트/레벨 아님 → D-19 "게이미피케이션 아님" 준수).
② "오늘의 한 가지" 히어로 — 요약 카드 상단에 top-1 미션의 현재→목표 거리감만 큰 게이지로. 나머지는 접힘(one-thing).
③ 도달 축하 마이크로 배지 — 목표 각도 도달 시 감점 카드가 초록으로 전환 + "해냈어요" 1회 표기(장난스럽지 않은 담백한 확인). 안전 결함엔 절대 미적용(D-14).

belle 결정 필요: 적용 범위 A / B / C(+추가 아이디어 채택 여부). 결정은 32-10(감점 카드)·32-07(요약/토큰)이 소비.

③ 최악 데이터 케이스 + 엣지 (ux-propose-user-centric-screens-first)
