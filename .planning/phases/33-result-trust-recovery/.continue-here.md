|---|---|---|
| single-motion-fixation | blocking | 한 동작 매몰 수정 금지 — 모든 fix·규칙은 동작별 데이터 소스(record.jointKeys·criterion·33-A1 표·technique)로 키잉, 완료 전 등재 10동작 일반화 확인. memory: fix-generalize-beyond-discussed-motion |
| code-only-verification | blocking | 코드 통과·렌더 확인 ≠ 완료 — 33-G 표 항목별 재채점(승인 목업 대조)까지가 검증(D-40). 산출물을 직접 열 것. memory: verify-against-approved-mockup-not-just-code |

| over-generalize-breaks-approved | blocking | 한 승인 자산에서 뽑은 규칙을 다른 카드 종류로 확대해 **이미 PASS인 항목을 깨뜨리지 말 것** — §C-1에서 실제 발생(220px 정중앙 crop을 split 카드에 적용하니 S10 렌더 소멸 → L-10으로 범위 환원) |
