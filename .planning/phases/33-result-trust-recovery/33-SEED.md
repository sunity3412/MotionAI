# Phase 33 SEED — 결과 화면 신뢰 회복

> 근거: `.planning/phases/32-result-readability-3-omni/32-UAT-FINDINGS-2026-07-22.md`

## 왜 이 phase 인가

phase 32 목표는 "결과 화면이 읽히게" 였으나 belle 실기기 판정 = **미달**.
belle 총평: "너무 심각하게 엉망인데 이걸 어떻게 어디부터 수정해야할지".
**phase 32 마감 보류**, 발견을 반영하는 이 phase 를 먼저 완료한다.

belle 우선순위 원문: **"이게 제일 중요해.. 솔직히 이것만 되도 안 읽혀도 볼만할거다"** (확대비교)

## 이미 확정된 것 (재론·재질문 금지)

- **확대비교가 1순위.** 앵글 연구 성공을 전제로 미루는 것은 belle 이 명시 기각.
- **일러스트 스타일 = 2안 준실사 확정** (belle 3안 비교·1안 해부학 오류 지적·2안 선택 완료).
  남은 것은 전부 Claude 실행 — 결함별 세트 생성 → 해부학 전수 검수 → 앱 배선.
  **이것을 belle 승인 게이트로 되돌려 묻지 말 것** (2026-07-22 belle 지적).
- 수치는 **삭제가 아니라 자리 이동** — 감점 내역 투명 공개 원칙은 유지하되 설명 카드에서 뺀다.
- 작업 순서 = 확대비교 → 설명 계층 → 타이포·레이아웃 → 개별 버그 → 일러스트.

## 범위

### W1. 확대비교 재설계 (최우선)

실측된 결함 8종 — 32-UAT-FINDINGS §A 표 참조. 핵심:

1. **정은지 쪽에 표시가 없음** — 비교 대상이 안 그려짐 (내 영상만 선/원)
2. **배율 불일치** — 내 쪽 확대·인물 잘림 vs 정은지 전신
3. **3장이 같은 순간** (user 34 / ref 90 고정) → belle "중복 느낌"의 정체
4. **자세 국면 어긋나 보임**
5. **항목↔크롭 오연결** — "다리 스플릿"에 `left_shoulder` 크롭(55°)
6. **각도 배지가 PNG 에 구워짐** → W2 와 충돌, 앱 레이어로 분리 필요
7. 크롭이 인물 밖으로 잘림
8. `advisory` 항목이 데이터엔 있으나 시트 미노출

**손볼 곳:** 백엔드 crop 생성(`analysis/fault_zoom*`) + 앱 연결(`result.tsx:1215 selectedZoom` — region 첫 매치 반환이라 관절 정확도 없음).

**게이트: 목업 선행** ([[ux-propose-user-centric-screens-first]]). belle 실제 영상 프레임으로
수정된 확대비교를 먼저 보여주고 확인받은 뒤 구현. 목업은 이 phase Task 1.

### W2. 설명 계층 재배치

- 코칭팁·설명 카드에서 각도 수치 제거 → 행동 언어만
- 수치는 "점수 내역" 자리로 이동 (투명성 원칙 유지)
- **문구 모순 수정** — "점수에는 반영되지 않아요" ↔ "점수에 반영된 비교 순간"
- "참고하세요" 섹션에 무엇을 왜 보는지 안내 추가
- "이 지표 — … / 확인하기 — …" 대시 나열 → 문장화
- 근거: [[product-role-interpret-act-or-ask-coach]] ①해석 ②다음 행동 ③코치 질문

### W3. 타이포그래피 · 레이아웃

- **본문이 상단 상태바와 겹침** (belle 스크린샷 ②③) — safe-area/시트 헤더 오프셋 결함. **버그**
- 타입 스케일 일관성 전수 점검 (`theme/typography.ts` 토큰 적용 제각각 여부)
- 시트 제목 vs 본문 헤드라인 위계
- 좌우 여백 통일 (강조 박스·설명문·측정 블록)

### W4. 개별 버그 6건

1. 자세히보기 다시 눌러도 안 접힘
2. 자세히보기 → 엉뚱한 위치로 스크롤·정지
3. "오늘 고칠 것" 추가 항목 존재를 모름 (스크롤 어포던스)
4. 음성 안내 중간 끊김
5. "적용 중입니다" 재생 순서 — 멈춘 뒤 적용, 적용 후 재생
6. (개선) 음성 안내 시 영상 일시정지 + 해당 부위 강조

### W5. 일러스트 도입

2안 준실사 스타일로 결함별 세트 생성 → **해부학 전수 검수(사지 개수·관절 방향)** → 앱 배선.
belle 은 완성 후 육안 확인만.
