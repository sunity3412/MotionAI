# 36-02 — Google 로그인 + 게스트 승계

## 선행 (완료)

- Firebase iOS·Android 앱 등록 (내가 실행, 2026-08-30)
- Firebase Auth **Google provider 활성화** — belle 콘솔 토글.
  API 로는 불가했다: `POST defaultSupportedIdpConfigs?idpId=google.com` →
  400 `client_id cannot be empty`. OAuth 클라이언트 생성이 콘솔 전용이라 그렇다.
- 확보된 값: iOS `CLIENT_ID` / `REVERSED_CLIENT_ID`, web clientId.

## 한 일

1. `@react-native-google-signin/google-signin` 설치 + config plugin 에 `iosUrlScheme`.
2. `socialAuth.ts` — 게스트면 `linkWithCredential`(uid 유지), 아니면
   `signInWithCredential`. `credential-already-in-use` 는 `switched` 로 갈라 화면이 알린다.
3. 로그인·가입 화면 배선 (Google 만; 나머지는 안내 유지). 진행 중 버튼 잠금.
4. **네이티브 재빌드** — 새 네이티브 모듈이라 기존 dev client 로는 안 돈다.
   `expo prebuild` → `pod install` → `expo run:ios`.

## ★검증의 한계 (정직)

Google 로그인 완주에는 **실제 구글 계정 자격증명 입력**이 필요하다. 내가 할 수 있는 것은
**구글 로그인 화면이 뜨는 것까지** — 그것으로 네이티브 모듈·URL 스킴·클라이언트 ID 배선이
맞다는 것은 증명되지만, `linked`(uid 유지)까지는 belle 이 한 번 로그인해야 확인된다.

승계 실증 방법 (belle 이 로그인한 뒤):
1. 게스트로 분석 1건 이상 만든다.
2. 마이 탭에서 uid 앞 4자리를 적어 둔다.
3. 로그인 화면 → Google 로그인.
4. uid 가 **그대로**이고 기록 개수가 **그대로**인지 본다.

- 게스트 기록을 기존 계정으로 옮기는 마이그레이션 — 서버 작업, 파일럿 범위 밖.
