- 폼: 모든 입력에 `<label for>` / `accessibilityLabel`, 필수는 `[필수]` 글자(색만 금지). 오류는 입력 아래 인라인 + `aria-live="polite"`. 탭/세그먼트 = `role="radiogroup"` + `role="radio" aria-checked`, 좌우 화살표 이동. 체크 행 = `role="checkbox" aria-checked`, 행 전체 탭.
- 비활성 CTA(#FFB7AD)는 `aria-disabled="true"` + 바 위 `필수 항목 {n}개가 남았어요`(`aria-live`)로 이유를 준다.
- 검증 다이얼로그: `role="dialog" aria-modal`, 포커스 트랩, ESC·백드롭 = `닫기`, 열릴 때 제목에 포커스.
- 복사: `navigator.clipboard.writeText` → 토스트 `복사됐어요` + 버튼 라벨 2초 `복사됨`(`aria-live`); 실패 시 `user-select: all` + `길게 눌러 복사하세요`.
- 업로드: `role="progressbar" aria-valuemin=0 aria-valuemax=100 aria-valuenow`; 취소 가능(인터럽트, apple-design §3); 업로드 중 `beforeunload` 경고.
- 키보드 포커스(웹): `:focus-visible { outline: 2px solid #FF4B33; outline-offset: 2px }`.
- 비디오 미리보기: `muted playsinline controls`, 자동 재생 없음.
- 텍스트 200% 확대에서 가로 스크롤 없음(고정 높이 텍스트 상자 금지 — 입력 54·CTA 54 만 고정).
- 헤더 위 흰 글자는 Display(large)와 17/700 1줄만(대비 §Color).
- 앱 B: `InfoRow` 는 `accessible` 컨테이너 1개로 읽힌다. 앱 C: `PickErrorDialog` 기존 접근성 그대로.
