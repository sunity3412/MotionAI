# Phase quick-260620-0r0 Plan 01: Mode3 점수 역전 버그(#8) 수정 Summary

`_mode3_comparison` 두 번째+ 분석의 overall 산출 source 를 angle 포함 dict(`dim_scores`)에서 절대 차원 dict(`abs_dims`)로 바꿔, mode3 의 angle(=이전 영상 대비 유사도)이 사용자 발전 시 떨어지며 종합을 끌어내리던 역전(belle 기기: 틀린 kip-up 98 → 올바른 영상 88)을 제거했다.

## What Was Built

### Task 1 — overall source 수정 + 주석 갱신 (`ba5fe4f`)
- `backend/functions/pipeline/app.py` `_mode3_comparison` 두 번째+ 경로:
  `overall = dimensions.overall_from_dimensions(dim_scores)` → `...(abs_dims)`.
- 첫 분석 overall(`abs_dims`)과 동일 source 가 되어 세션 간 같은 척도. `overall_from_dimensions` 의 `min(CORE_DIMENSIONS)` 가 angle(유사도)을 더 이상 종합에 끌어들이지 않음.
- `dim_scores`(= `{angle, line, stability}`)는 함수 반환 tuple 의 dimension_scores 로 그대로 유지(표시/일관성 지표).
- stale/모순 주석 블록("모든 차원 평균")을 교정된 동작(절대 차원만, #8 사유 명시, delta 미변경)으로 재작성. dimensions.py / delta 경로(`cur_dimension_scores=abs_dims`) 미변경.

### Task 2 — 회귀 테스트 (`751c4b0`, TDD)
- `test_low_similarity_does_not_invert_overall()` 추가.
- 결정적 입력: well-extended 현재 영상(line 99, stability 100) vs 다른(약 140~155°) 과거 영상 → angle(유사도) 22.
- 전제 가드 `dims["angle"] < min(abs_dims.values())` 성립 확인.
- 단언: `overall == overall_from_dimensions(abs_dims)`(=99), `overall >= overall_from_dimensions(dims)`(angle 포함=22), `"angle" in dims`.
- RED 증명: 수정 전(`dim_scores`) overall 은 22 → 단언 1(22 != 99) 실패. 수정 후 99 로 통과.
