# Quick Task 260716-jg6: phase22 v6 학습셋 assemble + terra13 union

## 목표

SFT v6 가 물 `train.jsonl` / `val.jsonl` / `_meta.json` 을 S3 `training/phase22/jsonl/` 에
올린다. 반영 항목:
- **B 재균형** (fault-free 를 fault-bearing 대비 1.5배 이하로 캡) — wq9 에서 코드 커밋 완료.
- **C1 descope** (`include_perturb=False` → perturb 트랙 0) — wq9 에서 코드 커밋 완료.
- **terra13 union** — GPT terra 교사가 Gemini 가 놓친 결함을 찾은 13영상의 faults 병합(신규).

SFT 실행(Pod)은 **이 quick 범위 밖** — belle 이 Pod 기동하면 별도 진행.

## 배경 (사전 조사 결과 — 재발견 불필요)

### 데이터 상태
- 현재 S3 `jsonl/` = **pre-v6** (perturb 166 + distill 149 + text 48, B/C1 미적용, terra 미반영).
  `_meta.json` 에 `fault_free_cap_ratio` 부재 + perturb 잔존으로 확인됨.
- distill `accepted/` 라벨(full_batch 산출)이 **종료된 Pod 볼륨과 함께 소실** → 로컬/S3 어디에도 없음.
- 단, **현재 `train.jsonl` 의 distill 149행이 accepted 라벨을 무손실로 담고 있음**:
  각 행 = `{messages:[system,user,assistant], _track:"distill", _video_hash, _motion}`.
  - `s3_key` ← user video part `s3://sunity-motion-pilot-videos/<KEY>` 에서 prefix 제거.
  - `coords_by_frame` ← user text `RTMW_Data: [...]` 파싱(`json.JSONDecoder().raw_decode`).
  - `joint_keys` ← system 메시지의 `[left_ankle, left_elbow, ...]` 대괄호 리스트 파싱
    (또는 coords_by_frame 프레임 dict 키에서 `frame` 제외 후 정렬 — 둘이 일치해야 함).
  - `report` ← assistant content 에서 `</thought>` 뒤 JSON 파싱(`build_jsonl.assistant_report` 로직 재사용 가능).
  - `thought` ← `<thought>...</thought>` 사이 문자열.

### terra 수집
- `.planning/quick/260715-wq9-.../overnight-artifacts/terra_collect.jsonl` (149행).
  각 행 = `{_video_hash, s3_uri, _motion, gemini_fault_count, terra_fault_count, terra_report, ...}`.
- **union 대상 = `terra_fault_count > gemini_fault_count` 인 13영상**(사전 확인, 아래 목록):
  `8ef78c0ae977(pole-split)`, `83623eee29e1(Ayesha)`, `68cc0c09fe30(Inverted-crucifix)`,
  `0b84677dd174(vertical-split)`, `2f00de7f233c(Inverted-split)`, `9a7d87a2cf47(inside-leg-hang)`,
  `d5aabb3d5d22(FlyBy-Straddle-Cartwheel)`, `dff1255baa90(Ballerina)`, `a73ef703515c(Fireman-spin)`,
  `1589e1c90f5c(General-pole-movements)`, `1f1f6ba788d6(chopper)`, `43f85e446ce4(geumgangmakgi)`,
  `95180a8429f0(invert)`. (스크립트는 하드코딩 말고 **비교로 재도출** — 목록은 검증 대조용.)
- union = 해당 video_hash 의 report `faults[]` 에 terra_report `faults[]` 를 append.
  gemini=0(정타 오판) 영상 8개는 fault-bearing 으로 승격(8복구).

### 재조립 파이프라인 (canonical, 무변형 사용)
- `full_batch.assemble_jsonl(manifest, accepted_dir, out_dir, ...)`:
  → `manifest_with_hashes(manifest, accepted_dir)` 로 s3_key→video_hash 주입(manifest 원본 239행은 video_hash 부재)
  → `build_dataset(manifest=m, distill_loader=<accepted_dir 읽기>, include_perturb=(perturb_loader is not None)=False, ...)`.
- `build_dataset` 이 자동 적용: **B** `_cap_fault_free(media, 1.5)`, **C1** perturb 미조립,
  **split** video_hash 단위 train/val(leakage 0, 이 모듈 단독 소유), **_meta** 방출.
- **F1 계약 필터 주의** — `_build_distill_samples` 는 `_faults_satisfy_contract` 미충족 report 를
  **행 전체 폐기**. 계약 = 각 fault item 이
  `(student_angle_deg AND reference_angle_deg 둘 다 not None) OR approx_angle_deviation_deg not None`
  + `fault_category` truthy + `body_part` truthy.
  terra faults 는 `student/reference_angle_deg:[null,null]`(리스트=not None) + category/body_part 보유라
  통상 통과하지만, **normalize_report 후에도 통과하는지 13영상 각각 사전 검증** 필수.
- `assert_collection_complete` — manifest `_meta.collection_complete=True` 확인됨(통과).
- `_eligible_media_row` — 149 distill 행은 원래 빌드 때 통과분이라 재통과.

## Tasks

### Task 1 — `assemble_v6.py` 작성 (복원 + terra union + assemble)
**Files:** `.planning/quick/260716-jg6-phase22-v6-assemble-terra13-union-sft/assemble_v6.py`

**Action:**
1. 입력: 현재 S3 `training/phase22/jsonl/train.jsonl` 다운로드(로컬 tmp).
   terra_collect.jsonl(위 경로). manifest = `backend/training/data/manifest.json`.
2. **복원**: train.jsonl distill 149행 → accepted 레코드 dict 리스트
   `{video_hash, s3_key, motion, thought, report, joint_keys, coords_by_frame}`.
   - `sys.path` 에 `backend/training` 추가 후 `from datagen import build_jsonl, schema` /
     `from distill import full_batch, gemini_teacher as gt` import(코드 재사용, 로직 복붙 금지).
   - report 파싱은 `build_jsonl.assistant_report`(있으면) 또는 동일 `</thought>` 분리 로직.
3. **terra union**: terra_collect 에서 `terra_fault_count > gemini_fault_count` 인 행 선별(13 기대).
   각 video_hash 매칭 accepted report 의 `faults` 에 terra_report faults append.
   - **계약 안전장치**: union 후 `schema.normalize_report(report)` → `build_jsonl._faults_satisfy_contract`
     검사. False 면 **방금 추가한 terra fault 를 하나씩 제거**하며 재검사(gemini fault 는 보존).
     드롭한 terra fault 는 `log()` 로 명시(은폐 금지). 최종적으로 각 행이 계약 통과 보장.
   - dedup: 동일 `(fault_category, body_part)` 는 중복 append 금지(gemini 우선).
4. **accepted_dir 물리 복원**: `full_batch.save_accepted` / `_accepted_path` 규약(slug=`gt._trial_report_path`)
   으로 tmp accepted 디렉토리에 `<slug>.json` 기록 → `assemble_jsonl` 이 그대로 읽게 함.
   (또는 assemble_jsonl 이 요구하는 distill_loader 계약을 직접 검토해 최소 경로 선택 — 단
   **manifest_with_hashes + build_dataset 은 무변형 호출**.)
5. **assemble**: `full_batch.assemble_jsonl(manifest, accepted_dir, out_dir=로컬 tmp, uploader=None,
   validation_owner="explicit_val_jsonl")` → perturb_loader 미주입 → include_perturb=False(C1) +
   B cap 자동. S3 업로드는 Task 2 에서 별도(uploader 미주입 = 로컬만).
6. `--dry-run`(기본) 시 로컬 산출만+분포 리포트, `--emit` 시 로컬 파일 확정.

**Verify:** `python3 assemble_v6.py --dry-run` 이 예외 없이 로컬 train/val/_meta 산출 +
아래 검증 지표 출력.
**Done:** 스크립트가 로컬 v6 산출 + 검증 리포트를 낸다. 커밋(스크립트만).
