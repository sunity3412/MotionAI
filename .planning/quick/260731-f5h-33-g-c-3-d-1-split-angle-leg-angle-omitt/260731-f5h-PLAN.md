  ① **출력 분리** — `--out {before|after}` 로 `sweep_out/{label}/` 에 PNG + `summary.json` 을 쓴다.

  ② **다리 사이각 전용 검출 = A/B 픽셀 오라클 (임계값 0개).**
     `_panel_has_angle` **재사용 금지** — 그것은 패널 정중앙 반경 16px 의 S8 각도 호 판정이라

     정중앙이 아님).
     브랜드 픽셀 **카운트 임계**도 쓰지 않는다 — 폴백 원 마커가 같은 `_BRAND` 색
     `r=int(_OUT*0.16)=57`·`width=4` 링이라 픽셀 수가 다리 선+호와 같은 자릿수여서 분리가 나쁘고
     임계 근거를 댈 수 없다.
     대신 같은 카드를 두 번 렌더한다:
       (A) 정상 렌더
       (B) `fz._draw_leg_angle` 를 "인자 무시하고 False 반환"하는 no-op 로 교체한 상태의 렌더
       `leg_drawn = (png_A != png_B)`
     근거: `_draw_leg_angle` 가 False 를 주면 `_draw_side_leg_angle` 도 False → 호출측이 원 마커로
     폴백하므로 픽셀이 **반드시** 달라진다. 반대로 정상 렌더가 이미 폴백 중이었다면 두 산출이
     byte-동일하다. 즉 `png_A != png_B` ⟺ 다리 사이각이 실제로 픽셀에 그려졌다. 추정 0, 임계 0.
     교체는 try/finally 로 반드시 원복한다. 디스크에 저장하는 PNG 는 (A) 정상 렌더분이다.
     **참고 컬럼**으로 `brand_px_user`/`brand_px_ref`(패널별 `_BRAND` 색 픽셀 수)도 기록해
