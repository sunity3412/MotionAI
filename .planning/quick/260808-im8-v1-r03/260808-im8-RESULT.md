## 9. 한계

1. **홀드 파라미터 민감도 (verdict 는 p40 고정 — 아래는 관찰만, 판정 불변)**:
   - p30: 5동작 전부 동시 홀드 짝 0 (더 엄격 — 동일 결론).
   - p50: pdshapefault 만 홀드 짝 17 성립 — 홀드 스크린에서 bodyline scaled 0.054 /
     gap_hip_mid 0.083 (<1.0, G2 가 보려던 침묵 방향과 정합). elbow 는 p50 에도 user 홀드
     0건 (run 조각내기 잔존). 즉 p40→p50 완화로도 G1 대상(elbow)은 세워지지 않는다 —
     임계만의 문제가 아니라 run 조각내기+DTW 교집합 구조의 문제.
2. **파일럿 촬영 가정**: 고정 카메라 + 화면상 수직 폴 (POLE_X_CACHE 는 08-08 세션 프로브
   실측 고정값 — 다른 촬영 환경 일반화 미실측).
3. **x-투영 원리 한계**: 깊이/y 축 이동은 폴간격 x-투영에 안 보임 (pdshape r01 그립 짝
   fail-closed 이력, epy SUMMARY — 같은 한계가 이 스크린의 gap 피처에도 적용).
4. **5동작 표본**: 판정·회귀 전부 이 데이터셋 한정. 좌표 관례 판별(§6)도 v0 수치가 남은
   powerspin 1동작 실측 기반.
5. **정규화 좌표 공간 관례**: v0 재현을 위해 채택 — px 공간·렌더러 실측과 수치 직접 비교
   불가(방향·자릿수 대조만 가능). 각도 피처(무릎각 등)는 정규화 공간에서 해부학 각도와
   다른 값이 됨 (세로 영상 W != H 왜곡) — 스크린 내부 비교용으로만 유효.
6. **홀드 판정 불가의 이중 원인** (§2): 상대 임계(p40)의 run 조각내기 + DTW 짝-홀드 경계
   불일치. v2 가설(다음 라운드 결정용, 이번 구현 아님): 히스테리시스 이중 임계(진입/이탈
   분리)로 조각내기 완화, 또는 "양쪽 모두 홀드" 대신 "한쪽 홀드 + 상대 저에너지" 완화짝.
