# 수술 ③ 스왑 가설 기계검증 — 기각 (quick-260808-r82 라운드 2)

**판정: 좌우 L/R 열 스왑 채점은 각도 공간에서 실측 기각. 프로덕션 스왑 미발동
(관측 로그만 유지).**

## 가설과 검증 설계

가설(보드 착수 블록 수술 ③): 미러 수행(그립팔 좌우 거울상) 시 right-vs-right
비교가 "그립팔 vs 자유팔" 비교가 되므로, 기능 동등 관절끼리 짝을 바꾸면 편차가
정당해진다. 근거 실측 = 엘보 doc: user 오른손목-폴 x간격 0.20 vs ref 왼손목-폴
0.20 (08-08 폴 프로브, 거울상 확정).

검출기(그립측 판별) 투자 전에 **가설 자체**를 기계검증: 유일한 실측 거울상
doc(elbow)에서 ref 각도 행렬의 L/R 열을 강제 스왑하고 편차가 개선되는지 측정.
변형 3종 (probe = `swap_hypothesis_probe.py`, 데이터 = 리포 영구화 doc 7종 +
Firestore 기준 각도 캐시, 수술 ② ref-경계 제외 적용 상태):

- **arms**: elbow/shoulder 쌍 스왑 후 DTW 재정렬 포함 재채점 (프로덕션 배선 형상)
- **full**: 4쌍(팔+다리) 전부 스왑 후 재정렬 (각도 공간 전신 미러)
- **pairing-only**: 정렬은 원본 유지, per-joint 짝만 스왑 (역할 대응의 순수 형태)

## 판정 근거

1. **유일한 실측 거울상 케이스(elbow)에서 악화** — 가설이 참이면 최소한 이
   doc 에서는 스왑이 개선을 보여야 하는데, 세 변형 모두 악화했다. DTW 거리
   자체가 악화(63→70)한 것은 스왑된 기준이 전역적으로 덜 맞는다는 뜻이다.
2. 스크린 v0(위치 공간 전신 스왑, 5동작 미개선 기각)과 합치면: 위치 공간에서도
   각도 공간에서도, 전신에서도 국소(팔)에서도 스왑은 기각. "관절각은 미러-불변
   스칼라라 열 교환으로 충분"이라는 이론은 실측이 반박 — 2D 투영·카메라 기하가
   각도의 좌우 대칭을 깨는 것으로 해석한다 ([[evidence-outranks-prior-decisions]]:
   판정은 이론이 아니라 측정).
3. **N=1 한계 정직 박제**: 실측 거울상 수행은 elbow 하나다. 미래의 진짜 거울상
   업로드에서 반대 증거가 나오면 이 판정은 데이터로 재개된다 — 단 채택 조건은
   그때도 "거울상 doc 에서 일관 개선"이지 이론이 아니다.

## 처분 (라운드 2 반영)

- 프로덕션 mode1 call site: 스왑 발동 제거 — 그립 거울상 감지는 **관측 로그만**
  (`side_match 그립 거울상 관측 ... 스왑 미적용`). 향후 표시 귀속 신뢰·피처 뱅크
  입력 후보 (belle "자체적으로 찾는 것" 방향).
- `side_match.grip_side` = 관측 전용 존치 (스핀 계열 ratio 2.4~5.0 안정 판별 실측,
  `data/side_report.md`). `swap_lr_arm_columns` = 하네스/가설 재검 전용 존치.
- `_deviation_against(swap_lr_arms=)` 파라미터는 불변식 3 테스트·재검용 존치,
  프로덕션은 항상 기본값 False.
- 위험 제거가 이 라운드의 실익: 방치 시 검출이 잘 되는 스핀 계열에서 미러
  수행자가 나오면 기각된 변환이 발동해 점수를 악화시켰을 것이다.

## belle 반려 "좌우 혼동" 잔여 소관

채점 짝은 기각으로 종결. 표시 계층("오른팔꿈치" 카드가 미러 수행에서 코칭으로
오독될 수 있는 문제)은 별개 결정 — 후보: 그립 거울상 감지 시 팔 record 의
attributionReliability 강등(역립 귀속 선례 계약 재사용). 단 elbow 계열(양팔
그립)은 판별 자체가 원리 불가(ratio 1.1~1.3)라 커버리지가 스핀 계열에 국한된다.
제품 표면 결정이므로 belle 판단 대상으로 이월 — 무단 구현하지 않음.
