belle 08-09 우선순위 1번. 결과 화면 두 자리(영상 재생 중 우상단 `renderCueIllustration`,
확대 상세 시트 `illustrationSlot`)는 **이미 배선돼 있고**, 승인 자산 있는 7동작에서는
정상 동작한다. 비어 있는 것은 자산뿐.

## 착수 시 확인 (추측 아님)

- 등재 기준 모션 **11개** 중 일러스트 보유 **7 / 미보유 4** (Firestore `reference` 조회).
- 미보유 4 = combo · pdshape · peter-pan · sideway-spin.
- **시도한 적 없는 게 아니다** — 33-14 가 10동작 전수에 같은 파이프라인을 돌려 6 PASS.
  실패 4동작이 지금의 미보유분과 겹친다(elbow 는 이후 plf 가 `--arm` 으로 통과).
- 33-14 실패 주 사유 = **② 자세 충실 — 앵커 앉은 자세 복제**(8회 중 다수).
  그 뒤 plf 가 앵커 규칙을 **L-6**(같은 동작 통과본 > 같은 방위 통과본)으로 바꿔 3/3 PASS.
  → **떨어진 동작들은 고쳐진 규칙으로 재시도된 적이 없다**는 것이 이번 재시도의 근거.

## 2차 라운드 — 대안 4종 전수 소진 (belle "실패하면 대안이 뭐야")

pdshape 를 살리기 위해 대안 4종을 전부 실행했다. **전부 같은 자리에서 실패.**

| 대안 | 실행 | 결과 |
|---|---|---|
| A. 입력 프레임 교체 | hold 창 1초 간격 8컷 열람 → 8.25s(접힘 최대) → **5.0s**(머리-골반 분리) | try3 = **머리 2개** |
| B. 프롬프트 경화 | ANATOMY 에 "머리 1개·목 부착·골반 융합 금지·중복 금지·겹침 윤곽" 추가 (내 사본만, 승인 레시피 무접촉) | try4 = 축소본 개선, **2x 확대에서 머리-어깨 융합 잔존** |
| C. 프레이밍 완화 | 머리를 프레임 밖으로 (승인 선례 `ref-kip-up--shoulder` "다리는 프레임 밖") | try5 = 해부학은 피했으나 **hook 무릎이 덩어리로 읽힘** = 코칭 전달 실패 |
| D. **다른 모델** | Magnific **Seedream 5 Pro** ×2 (참조 2장 업로드 → 동일 프롬프트) | sd1·sd2 = **Gemini 와 동일한 머리-골반 융합** |

**결론(근거 있는 확정)**: 실패는 모델 특성이 아니라 **자세 자체**다. pdshape 는 도립 상태로
몸을 접어 **머리가 골반 옆에 매달리고 사지가 겹치는** 구조라, 두 모델 계열 모두 머리를
몸의 덩어리로 그린다. 33-14 3회 + 오늘 5회(Gemini) + 2회(Seedream) = **10회 동일 실패**.

## 3차 — 돌파 (belle "하나라도 불가능하면 기능 자체를 못 넣어")

포기 판단은 성급했다. 안 써본 조합이 하나 남아 있었다 — **부분 프레이밍 앵커**.

try1~5 는 입력만 좁히고 **앵커는 계속 전신본**이었다. 전신 앵커가 전신을 그리게 만들고,
그 전신에서 머리-골반이 융합했다. 승인 자산 중 `ref-kip-up--shoulder` 는 **"다리는 프레임 밖"**
으로 통과한 **부분 구도** 자산이다. 그것을 앵커로 쓰면 부분 구도 자체가 스타일로 전달된다.

| 자산 | 채택 시도 | 구성 | 판정 |
|---|---|---|---|
| **ref-pdshape--leg** | **try6** | 입력 = 무릎 잠금부 크롭 / 앵커 = **kip-up--shoulder(부분 구도·원 가이드)** | **PASS** — 원이 정확히 무릎 관절, 허벅지→무릎→종아리가 폴을 감은 것이 읽힘. 2x 확대에서 슬개골·근육선 정상, 이상 0. 머리·팔이 프레임 밖이라 융합 문제 자체가 소멸 |
| **ref-peter-pan--leg** | **try2** | 입력 = 신전 다리 크롭 / 앵커 = foxtop-split(신전+직선) | **PASS** — 직선이 고관절→무릎→발끝, **발끝 밖 초과 없음**(33-14 try3 FAIL 사유 해소), 발가락 5개, 무릎 신전 |
| **ref-sideway-spin--leg** | try2 | 전신 / 앵커 = foxtop-split | **PASS** (1차 라운드) |

**일반화된 규칙 2개 (동작명 분기 아님 — 데이터 성질로 키잉)**

1. **앵커는 방위가 아니라 "의도"로 고른다.** sideway 는 *자세 의도*(신전+직선),
   pdshape 는 *구도 의도*(부분 프레이밍)가 맞는 통과본에서 성공했다. L-6 의 "같은 방위"
   규칙만으로는 sideway·pdshape 둘 다 실패했다(실증).
2. **전신 렌더가 어려운 자세는 부위만 프레임에 둔다.** 접힌 도립처럼 머리·사지가 겹치는
   구조는 두 모델 계열 모두 실패하지만, 부위만 그리게 하면 통과한다. 승인 선례 존재.
