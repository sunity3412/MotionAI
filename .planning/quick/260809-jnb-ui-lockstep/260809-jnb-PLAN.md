## 작업

### T1. 각도 수치 짝 lockstep (백엔드 렌더러)
- 파일: `backend/shared/.../analysis/compare_render.py`
- 조치: `_pair_lockstep_degrees()` 순수 함수 — 한 패널이라도 `deg` 없으면 양쪽 다 생략.
  기존 both-or-neither(패널 유무) 규칙의 **수치판 확장**. 쐐기·호 좌표 무접촉.
- 반대안 기각: 신뢰 낮은 쪽도 억지 표시 = 부정확한 수치 송출 → 분석 정확도 원칙 위반.
- 검증: 유닛 6건 + 전체 스위트 기준선 불변 + (다음 Pod) 실렌더 눈검증
