## 한 줄

표시 순간이 "안 보이는 순간"인 게 아니라 **애초에 감점을 잰 순간이 아니었다.**
저장된 초가 실제보다 **9.7~10.0% 크다** — `frame_extractor` 가 정수 step 으로 솎는데
초 환산은 요청값 `target_fps` 를 쓴다.

## 뿌리 (기계 재현됨)

```
frame_extractor.py:44   step = max(1, round(src_fps / target_fps))
                        → 실제 산출 rate = src_fps / step ≠ target_fps
pipeline/app.py:2535    video_sec = frame_idx / _pipeline_frame_fps()   # = target_fps(9.0)
compare_align.py:262    ui = clip(round(atVideoSec * 15), 0, uF-1)      # 사용자 프레임 = 그 초 그대로
```

30fps 원본 → `step 3` → 실제 **9.997fps**. 그런데 record 는 `atFrameIdx / 9.0` 로 초를 만든다.

**저장 트랙 프레임 수가 이 규칙으로 4/4 케이스 정확히 재현된다**(강제 마지막 프레임 규칙 포함):

- 08-09 "표시 순간의 차이가 클립 중앙값보다 작다" — 근처지만 틀린 프레임이라 중앙값을
  보여줄 이유가 없다
- **peterpan r00: 저장 초 6.444s → 15fps 프레임 97번인데 클립은 91프레임(0~90)**.

## 할 것 1 — 조건부 표시 순간: 축이 서로를 잡아먹는다 (그리고 직교화)

`(차이 큼) ∧ (포즈 신뢰) ∧ (정렬 신뢰)` 를 그대로 걸면 후보의 차이가 125~168도로 나오고,
08-09 에 폐기된 "최대 차이 순간"(다른 국면/깨진 포즈)과 같은 자리다. 이유는 구조적이다 —
`_pose_dist` 가 **지적 관절의 위치 차이까지 포함**해서 재므로 "잘 맞는 짝에서 큰 차이"는
자기모순이다.

**직교화**: 정렬을 **지적 관절 3점을 뺀 나머지 몸**으로 재면(`pd_rest`) 두 축이 독립하고,
그것이 코치가 하는 말의 구조다 — "다른 건 같은데 이 부위가 다르다".

★**정정**: 1차에 "승인 순간이 클립 최악의 정렬(상위 87~100%)"이라고 쟀는데, 나머지몸
기준으로는 **상위 11~78%(대부분 20~44%)** 다. 앞 수치는 정렬이 아니라 그 관절이 벌어진
정도를 재고 있었다.

나머지몸 기준 Pareto 우세(정렬 ≤ 현행 ∧ 차이 > 현행) 후보 = **record 10건 중 7건 보유**.
단 후보 각도가 `16도 대 176도` 처럼 나오는 건이 있어 **2D 전단축(foreshortening)** 게이트가
따로 필요하다 — 팔·다리가 카메라를 향하면 투영 길이가 0에 수렴해 각이 의미를 잃는다.
채점은 3D인데 카드는 2D 각도를 그린다는 공간 불일치도 여기 얽힌다.

**단, 이 측정은 앵커가 틀린 상태에서 한 것이다.** 표시 순간 규칙을 바꾸는 것은
단위 교정 **뒤에** 판단해야 한다 — 순서가 생겼다.

## 할 것 2 — `편차 ÷ 요동` 지표: 버린다

- 창 폭 교정(9 → 10 프레임)에 **robust — 판정 뒤집힘 0/10건**. 지표 자체는 안정적이다.
- 그러나 **요동이 130~180도**다. ±0.5초에 관절이 거의 전 범위를 돈다는 뜻이고, 회전·역립
  동작이면 비율은 **구조적으로 항상 0.1 미만**이 된다. belle 이 통과시킨 peterpan 만
  요동 36도(비율 0.383) = 어깨가 안정된 국면.
  → 이 지표는 카드 품질이 아니라 **"그 동작이 안정 국면인가"** 를 재고 있다.
  belle 체감("한두 개") 대 내 지표(17/20)의 어긋남이 이걸로 설명된다.
- 게다가 앵커가 최대 1.1초 틀렸다.

**결론: 지표를 표시 정책의 근거로 쓰지 않는다.** 대체 축 후보 = **나머지몸 정렬
`pd_rest`** — 두 사진이 같은 국면인지를 직접 재고, 위 표에서 카드 품질과 함께 움직인다
(powerspin r02 0.800 → 0.181).
