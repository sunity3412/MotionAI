## Task 1 — 게이트 순수 함수 (`gates.py`, 이 디렉터리)

- `hold_gate(report, kp_idx, joint)` — robust 각속도(±3f 중앙값 기반, 원시 지터 완화)
  < 임계. 저신뢰로 속도 측정 불가 = FAIL(fail-closed).
- `pair_gate(user_report, u_kp, ref_report, r_kp, pole_u, pole_r)` — 포즈거리(기존
  `fz.pose_distance`, basis 고정) + 몸중심-폴거리 parity(몸통 단위 차 < 임계).
  폴 축 검출은 bz5 부록 D 의 배경 중앙값 세로 에지 방식 재구현.
- `machine_eye(frame_rgb, joint_xy_px, claim)` — 관절 마킹 크롭 → Gemini
  (gemini-3.5-flash, temp 0, JSON) 판정. 좌우 이름 금지 — "표시된 부위" 지시.
  claim ∈ {bent, extended, off_pole}. bz5 부록 C 의 REST 패턴 재사용.
