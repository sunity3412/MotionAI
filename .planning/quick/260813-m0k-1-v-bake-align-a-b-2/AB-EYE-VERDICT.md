# B(align 유도 스펙) 소생 V 육안 사전 박제 (quick-260813-m0k)

판정 방식: `evidence/ab_cards/B/` **원본 카드를 Read 도구 원본 크기로 개별 열람**
(몽타주/축소본 검수 0 — 시트는 대조용 합성일 뿐). A 대비 변화 카드 = 소생 6장
전부 (changed 6 == recovered 6, 비대상 카드 md5 무변동 — 무누출).
판정 대상 = **옳게 살아났는가** (V 꼭짓점이 관절 위인가, 가닥 방향이 실물
포즈와 맞는가, ref 무마크가 해소됐는가, 환각 좌표인가). 각도 도 수치 없음
(범주 표기만). 마크 길이·위치 튜닝 0 (별건 — belle 미세조정 라운드 몫).
이 문서는 belle 판정 전 사전 박제다 — 결론을 미리 못 박지 않는다.

## 집계 (사전 박제 요지)

- 소생 6/6 전부 **꼭짓점이 해당 관절 위** — 환각 좌표(엉뚱한 부위 V) **0건**.
- ref 무마크였던 2장(피디쉐입 왼팔꿈치·왼무릎)은 ref 패널이 **부위 크롭 + V**
  로 회복 — "두 패널이 너무나 다른 화면"의 화면 격차가 크롭 수준에서 줄어듦.
  단 **짝 순간 자체는 반려된 그 순간 그대로** (national r2.4/r9.4) — 국면 문제는
  Task 2 짝 후보 재료가 담당 (크롭이 국면 불일치를 가린 것이지 푼 것이 아님).
- 반복 관측 한계: 소생 V 중 3장(엘보 r00 ref, 피디쉐입 왼팔꿈치 ref·왼어깨
  양패널)은 **저사이각** — 두 가닥이 겹쳐 선/화살표 하나로 읽힘 (ivs 어색
  케이스와 같은 범주, 마크 표현 별건).

## 카드별 판정

### 1. elbow r00 — zoom_angle_vs_reference__right_elbow (A: omitted:user_gate 원 앵커 -> B: V 양패널)

- user 패널: V 꼭짓점 = 오른팔꿈치 위 (굽힌 팔). 사지 가닥 = 전완(주먹 방향),
  몸통 가닥 = 상완/어깨 방향 — 실물 포즈와 정합. **옳게 살아남**.
- ref 패널: 꼭짓점 = 팔꿈치 추정 위치 (팔이 몸통 뒤로 가림 — A 원 앵커와 같은
  자리). 위치는 정합이나 **가림 + 저사이각**으로 두 가닥이 화살표처럼 읽힘.
  좌표는 옳고 표현이 약한 케이스 (환각 아님).
- seam 1 (user side), align conf 3점 전부 통과 (measure_B.json).

### 2. elbow r03 — zoom_angle_vs_reference__right_knee (A: 침묵[rep12 양측 신뢰 0] -> B: 신규 카드 + V 양패널)

- **무로그 침묵이 카드로 살아난 첫 실물** (fault_zoom 3184행 skip 자리).
- user 패널: 꼭짓점 = 오른무릎 위 (역립, 뻗은 다리). 가닥 = 허벅지/정강이
  방향 정합. ref 패널 동일 — 꼭짓점 무릎 위. **양패널 옳게 살아남**.
- 다리가 곧게 펴진 국면이라 저사이각 — V 가 선 + 반원 호로 읽힘 (표현 범주).
- seam 2(양측 주입) + seam 1(양측 spec), conf 전부 통과.

### 3. pdshapefault r00 — zoom_angle_vs_reference__left_elbow (A: ref_crop_relaxed, ref 전신 무마크 -> B: 양패널 크롭 + V)

- **ref 무마크 해소 실물** — A 는 ref 패널이 전신 폴백 + 마크 0 이었는데 B 는
  부위 크롭 + V. belle 반려 사유였던 "두 패널이 너무나 다른 화면"의 화면 형식
  격차가 사라짐.
- user 패널: 꼭짓점 = 왼팔꿈치 위, 가닥 = 손/어깨 방향 정합. **옳게 살아남**.
- ref 패널: 꼭짓점 = 왼팔꿈치 추정 위치 (머리카락에 일부 가림). 저사이각 —
  화살표처럼 읽힘. 위치 정합 판단은 가림 탓에 근사 (환각 정황은 없음).
- seam 2(ref 주입) + seam 1(ref spec), conf 통과.

### 4. pdshapefault r02 — zoom_angle_vs_reference__left_shoulder (A: ref_gate 원 앵커 -> B: V 양패널)

- 양패널 꼭짓점 = 왼어깨 관절 위 (역립 상체). 몸통 가닥 = 옆구리/골반 방향
  정합. 사지 가닥(팔꿈치 방향)은 팔 가림으로 단정 불가 — 미검증 표기.
- **구조 차이 명기**: B 스펙 꼭짓점 = align 어깨 관절 좌표. 운영 승인 문법의
  어깨 꼭짓점은 겨드랑이(어깨→골반 내분점)다 — B 채택 시 어깨 계열 카드의
  꼭짓점 자리가 승인 문법과 미세하게 다른 자리가 된다 (display_anchor 와는
  같은 출처라 정합). belle 판정 재료.
- 저사이각 — 선 하나로 읽힘.

### 5. pdshapefault r03 — zoom_angle_vs_reference__left_knee (A: ref_crop_relaxed, ref 전신 무마크 -> B: 양패널 크롭 + V)
