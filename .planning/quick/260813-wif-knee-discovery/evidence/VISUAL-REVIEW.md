# 육안 전수 확인 기록 — frames-before-numbers (quick-260813-wif, Task 1)

실행자(오케스트레이터 하위 실행 에이전트)가 evidence/stills/ 실물 64장을 **한 장씩
Read 로 열어** 확인한 기록이다. 수치(candidates.json)만으로 방출 후보를 선정하지
않았다. 판정은 belle 몫 — 이 문서는 실행자 관찰 기록이다. 이모지 0.

관찰 언어 규약: "폴측 다리" = 화면에서 폴에 가까운 쪽 다리 (좌/우 해부학 이름은
트랙 기준이라 화면 관찰에는 쓰지 않는다 — 마크된 관절의 좌우 판별은 기계 눈
단계의 몫, bz5 부록 C 관례).

  완전 신전 + 반대 다리 수평 뻗음. **결함 대조(접힘 vs 신전)가 그림으로 읽힌다**

  rAngle 142.3(중간각) — kpo 박제 "hold 양측 PASS·ref extended"와 불일치

## 관찰 한계 (박제)

- 전신 프레임에서 좌/우 무릎의 해부학 판별은 하지 않았다 (마크된 관절의 판정은
  기계 눈 + 카드 링 마크의 몫 — 좌우 이름 금지 관례).
- kpo 대조 행의 재계산 불일치 (ref hold moving / rAngle 142.3 vs kpo 박제
  "양측 PASS·extended")는 여기서 해석하지 않고 candidates.json 수치 그대로
  장부에 넘긴다 — 시각적으로 ref 12.2667s 폴측 다리는 신전으로 읽힌다 (트랙
  각도와 육안의 불일치 = 트랙 keypoint 정밀도 한계 후보, 환각 게이트 의제와
  같은 뿌리).
- 트랙 의심값 실물 확인: cand13b user 트랙 0.3도/kpo 행 9.0도 급의 극단 각도는
  "종아리가 허벅지에 완전히 접힌" 실물과 방향은 일치하나 수치 자체의 정밀도는
  보증하지 않는다 (수치는 보조, 실물이 정본).
