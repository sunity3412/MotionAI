## §1. 판정 규칙 (표 채우기 전 확정 — 2026-08-14)

### 1-1. 대상 집합

| 집합 | 정의 | 비고 |
|---|---|---|
| **P (통과)** | belle 이 통과시킨 V 카드 전건 ∪ {cand17B} | 승인 5동작 스윕에서 **V 가 실제로 그려진** 카드만. "카드가 있다"가 아니라 `fault_zoom_angle_bake=drawn` 로그가 있는 카드다 |
| **N (반려)** | {cand01E} | belle "각도 표기가 필요한 부분인진 모르겠음" |

★ P 의 원소는 **이번 실행 로그로 확정**한다. 과거 문서의 "V 보유 카드 2장"
(08-13 ivs 시점) 같은 숫자는 인용하지 않는다 — nh4 의 B 스펙 이식으로 카드가
8→10 으로 늘었고 V 보유 집합도 그때 바뀌었다.

### 1-2. 측정 축

전부 **운영 함수 `fault_zoom._spec_inner_deg_px` 를 그대로 호출**해 얻는다.
새 산식 발명 0 — 실제로 그려지는 spec·box·frame 으로 계산한 px 공간 사이각이다.

| 축 | 정의 |
|---|---|
| **A1** | ref 패널 V 사이각 (px 공간, degree) |
| **A2** | user 패널 V 사이각 (px 공간, degree) |
| **A3** | \|A1 − A2\| — 양측 대조량 |
| **A4** | 각 측의 **직선 근접도** `min(inner, 180 − inner)`. 0 에 가까울수록 "V 가 아니라 선 하나로 보인다" |
| **A5** | `deficitDeg` 및 tolerance 대비 |
| **A6** | 대조 방향 — 학생·기준 중 **어느 쪽이 더 굽었는가** (belle 이 "방향 반대"라 지적한 축). 굽음 = 사이각이 작은 쪽 |

### 1-3. 채택 규칙 (이 조건을 만족해야 임계를 정한다)

1. 어떤 축에서 **P 전건이 한쪽에, N 이 반대쪽에** 떨어진다.
2. 그 분리 마진이 **P 관측 산포의 20% 이상**이다.
   - 산포 = P 의 (max − min). P 가 1점뿐이면 산포 0 → 이 조건은 성립할 수 없다.
3. 둘 다 만족하면 그 축을 채택하고 임계는 **분리 마진의 중앙**에 둔다.

### 1-4. 미채택 시 (지어내지 않는다)

어떤 축도 1-3 을 만족하지 않으면 **임계를 만들지 않는다.** 대신:

- MEASURE.md 에 "측정 축 미발견"으로 적고,
- 대안 = `(motionId, criterion)` **선언 억제 표**를 Task 3 에 제시한다
  (`reference_anchor_overrides` 선례의 데이터 선언 — 동작명 코드 분기 0).

이것은 실패가 아니라 정직한 결과다. 갈리지 않는 축에 임계를 세우면 승인 카드가
조용히 죽는다 (T-rcz-04).

### 1-5. 표본 한계 (채택하든 선언하든 반드시 박제)

- **N 의 표본은 1건**(cand01E)이다. 어떤 규칙을 세우든 반례 1개에 맞춘 것이므로
  과적합 위험이 구조적으로 남는다.
- P 도 승인 코퍼스 1벌(5동작)에서 나온 것이고, 그중 V 가 실제로 그려진 카드만이라
  더 좁다.
- belle 이 이 한계를 보고 판정할 수 있도록 표 아래에 관측 수를 명시한다.
