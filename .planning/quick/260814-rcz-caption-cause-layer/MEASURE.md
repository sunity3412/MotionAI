### 1-3. 채택 규칙 (이 조건을 만족해야 임계를 정한다)

1. 어떤 축에서 **P 전건이 한쪽에, N 이 반대쪽에** 떨어진다.
2. 그 분리 마진이 **P 관측 산포의 20% 이상**이다.
   - 산포 = P 의 (max − min). P 가 1점뿐이면 산포 0 → 이 조건은 성립할 수 없다.
3. 둘 다 만족하면 그 축을 채택하고 임계는 **분리 마진의 중앙**에 둔다.

### 1-4. 미채택 시 (지어내지 않는다)

어떤 축도 1-3 을 만족하지 않으면 **임계를 만들지 않는다.** 대신:

- MEASURE.md 에 "측정 축 미발견"으로 적고,
- 대안 = `(motionId, criterion)` **선언 억제 표**를 Task 3 에 제시한다
  (`reference_anchor_overrides` 선례의 데이터 선언 — 동작명 코드 분기 0).

이것은 실패가 아니라 정직한 결과다. 갈리지 않는 축에 임계를 세우면 승인 카드가
조용히 죽는다 (T-rcz-04).

### 1-5. 표본 한계 (채택하든 선언하든 반드시 박제)

- **N 의 표본은 1건**(cand01E)이다. 어떤 규칙을 세우든 반례 1개에 맞춘 것이므로
  과적합 위험이 구조적으로 남는다.
- P 도 승인 코퍼스 1벌(5동작)에서 나온 것이고, 그중 V 가 실제로 그려진 카드만이라
  더 좁다.
- belle 이 이 한계를 보고 판정할 수 있도록 표 아래에 관측 수를 명시한다.

### 1-6. 이 Task 의 금지 사항

- 운영 코드 수정 (`git status --porcelain backend/ app/` 이 비어야 한다)
- 임계를 통과할 때까지 반복 조정
- 후보 좌표 재탐색 (발굴은 이미 끝났다)

## §3. 판정

### 3-1. 채택 축 = **A3 (양 패널 사이각 절대차)** · 임계 = **99.6도**

- 분리 구간 = (84.85, 114.40). 중앙 99.62 → **임계 99.6** (1자리 정밀도의 중앙,
  구간 내부에 엄격히 위치). 사전 규칙 §1-3 의 "마진 중앙" 그대로이며 표를 본 뒤
  조정한 값이 아니다.
- 규칙: `A3 >= 99.6` 이면 V 를 **억제**하고 기존 원 마커 폴백으로 떨어진다.

### 3-2. 왜 이 축이 belle 의 말과 맞는가 (숫자만으로 채택하지 않는다)

belle: "각도를 표기한다고 해도 **잘한 영상쪽 각도가 좀 애매해** 저렇게 표기하는게
맞는지 모르겠네".

카드 실물을 열어 대조했다 (frames-before-numbers — 로그만으로 판정하지 않는다):

- **cand01E (N)**: user 패널은 **직선 하나**(178.9도 — 각으로 읽히지 않는다),
  ref 패널은 **뚜렷한 V**(64.5도). 두 패널이 **서로 다른 종류의 마크**를 보여준다.
  → "한쪽 각도가 애매하다"의 실물.
- **elbow/right_elbow (P, 임계에 가장 가까움)**: user 103.5도 둔각 V, ref 18.6도
  예각 V. **양쪽 다 각으로 읽힌다** — 좁아도 두 선이 각을 이룬다.

즉 A3 가 재는 것은 "차이가 큰가"가 아니라 **"두 패널이 같은 종류의 마크를
보여주는가"** 다. A3 가 100도에 가까워지면 한쪽은 반드시 직선에 붙는다.

★반례로 확인된 것: **"한쪽 패널이 직선에 가깝다"만으로는 억제 근거가 못 된다.**
`pdshapefault/right_elbow` 는 user 177.4도(A4 2.62 — cand01E 의 1.09 와 거의 같은
직선)인데 ref 도 167.0도라 **양쪽이 함께 직선**이고 belle 이 통과시켰다. 그래서
A2·A4user 축은 마진 1.53 로 기각됐다. 갈리는 것은 **불일치**뿐이다.

### 3-3. 표본 한계 (belle 이 과적합 위험을 보고 판정할 수 있도록)

1. **N 의 표본 = 1건**(cand01E). 어떤 규칙이든 반례 1개에 맞춘 것이다.
   구조적 과적합 위험이 남는다 ([[scoring-redesign-must-generalize-no-overfit]]).
2. **P 의 표본 = 9건**, 승인 코퍼스 1벌(5동작)에서 V 가 그려진 카드 전부 + 채택
   후보 1건. 동작 다양성이 5개뿐이다.
3. **P 정의의 정직한 단서**: belle 이 **마크 문법을 이유로** 반려한 승인 카드는
   0건이다. 다만 08-13 ivs 스윕 판정(반려 2 / 통과 6 / 소프트 노트 2)은 그때의
   8카드 세트에 대한 것이고, **그 세트에서 V 가 실제로 그려진 카드는 2장뿐**이었다.
   nh4 의 B 스펙 이식 뒤 V 보유 카드가 8 로 늘었으므로 **P 의 다수는 belle 이 현
   형태로는 아직 보지 못한 카드**다. (ivs 반려 2건은 `짝 국면 불일치` · `원이 얼굴
   둘러쌈` 사유였고 마크 각도 문법이 아니었으며, 둘 다 이후 해소됐다.)
4. **임계 여유는 14.77도**뿐이다 — 가장 가까운 P(84.85)와 임계(99.6) 사이.
   A3 가 85~99 구간에 떨어지는 미래 카드는 **미검증 영역**이다.

### 3-4. 대안(미채택)과 그 이유

`(motionId, criterion)` **선언 억제 표**(§1-4 의 폴백)는 이번엔 쓰지 않는다 —
A3 가 사전 규칙을 통과했기 때문이다. 다만 belle 이 3-3 의 표본 한계를 이유로
A3 를 물리면 그 선언 표가 즉시 대안이며, Task 3 의 게이트 함수는 **시그니처를
바꾸지 않고** 임계 대신 선언 표를 읽도록 교체할 수 있게 만든다.
