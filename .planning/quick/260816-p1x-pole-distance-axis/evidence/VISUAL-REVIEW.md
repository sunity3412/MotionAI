수치·서술을 시트에 올리기 **전에** 실행자가 짝 스틸 실물을 직접 열어 본 기록

## 단위와 규율

- 단위 = 후보별 `{rid}_{cid}_PAIR_*.jpg` — 학생(좌)/기준(우) 30fps 1080p 스틸을
  무축소 가로 결합(8px 구분선). 마크/링/좌표 표시 **없음** — 이 사이클의 핵심
  차이(눈이 좌표를 보지 않는다)를 스틸 단계에서도 유지.
- 대상 = Task 2 실행 후보 **20건 전건** (elbow 16 + peterpan 4). 한 건도
  건너뛰지 않았다.
- 확인 항목: ① 두 패널이 같은 국면/요소인가 ② 붕괴·클립경계·오크롭 아티팩트가
  있는가 ③ 눈의 서술(differences[].description)이 사진과 실제로 맞아 보이는가.
- 이 확인은 "채택/반려" 판정이 아니다 — 판정은 belle 몫. 여기서는 재료가
  성립하는지(수치가 실제 화면과 무관한 값을 만들지 않았는지)만 본다.

**결과: 20건 전건 육안 통과 — 붕괴/오크롭 0건, 다른 국면 짝 0건.**

## 요약

- elbow 16건 + peterpan 4건 = 20건 전건 육안 통과. 국면 불일치/붕괴/오크롭
  0건 — 검증기 산출 수치가 화면과 무관한 것을 재고 있다는 의심은 없다.
- eye 서술과 사진의 정성적 일치도: 대다수 서술은 사진에서 "그렇게 보일 수
  있는" 방향이다(완전히 엉뚱한 서술은 없었다) — tie-band/rejected 로 갈린
  항목들은 방향 자체는 그럴듯해 보여도 실제 각도차가 크지 않거나(tie) 반대로
  측정되는(rejected) 경우다. 이것이 "눈은 후보를 낼 수 있지만 수치 확인이
  필요하다"는 이 사이클의 전제를 시각적으로도 뒷받침한다.
