## 1. 질문 자체가 틀렸다 — 게이트는 사진을 못 없앤다

`card_gates.verify_anchor_side` 의 docstring 이 못 박고 있다

## 3. ★게이트 확인이 사진의 정확성을 보장하지 않는다

정정 명부의 불일치 5면이 게이트에서 어떻게 처리됐는지:

| 동작 | 면 | 게이트 |

| pdshape [03] user left_knee | 불일치 | **억제**(표시 생략, 사진은 남음) |
| 파워스핀 [01] user left_shoulder | 불일치 | **억제**(표시 생략, 사진은 남음) |

### 단정 금지 — 여기서 두 계기가 다툰다

게이트의 눈은 **배달 전 크롭**을 보고, v2 계기의 눈은 **배달된 JPEG**를 본다.
같은 자리에 대해 답이 다르다. 알려진 미해결 차이 두 가지(픽셀 원천 = 원본 프레임 vs
배달 JPEG 재압축 · 창 좌표 클램프)가 남아 있고, 09-06 인계서도 이 건을
"원인 미상 — 단정 금지"로 남겼다. 이 표는 **"게이트가 틀렸다"의 증거가 아니라
"게이트 통과가 배달 사진의 정확성을 보장하지 않는다"의 증거**다.
