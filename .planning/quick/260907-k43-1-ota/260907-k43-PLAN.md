# 확대비교 방향 전환 — 슬라이스 1 (OTA)

belle 2026-09-07 승인: 자동 사진을 고치는 대신 **멈춤·확대를 사용자 손에** 준다.
belle 원문(09-06): "영상에서 음성 나올 때 멈춘단 말이지? 그때 캡처하기 버튼 또는
손가락으로 영상을 멈추고 확대할 수 있게 넣어주는건...?"

Step 0 실측(quick-260907-itk)이 이 전환을 뒷받침한다 — 좌표는 문제가 아니었고
(독립 모델이 임계의 2~35% 안에서 일치), 결함은 그 아래층(프레임 선택·크롭·표시)이다.
사용자 손에 넘기면 그 세 칸이 사라진다.

## 왜 슬라이스가 둘인가

| | 필요한 것 | 배송 |
|---|---|---|
| 멈춤·확대 | **새 네이티브 모듈 0개** | 오늘 OTA 가능 |
| 캡처 | expo-image-manipulator + expo-sharing | 1.2.5 빌드 |

확대가 OTA 인 이유: RN core `PanResponder` 가 이미 멀티터치를 준다
(`numberActiveTouches`, PanResponder.js:176/338/442-443) **그리고** 이 앱은 이미
제스처 라이브러리 없이 영상을 1.35배 확대하고 있다 — `VideoCompare.tsx:1941-1944`
의 레이아웃 확대(transform 아님 → 안드로이드 SurfaceView 에서도 동작).
그 상수를 상태로 바꾸는 것이 이 일의 전부다.
