## 실기기 전 시뮬레이터 실증

시뮬레이터에는 멀티터치 자동화가 없다(`xcrun simctl`·`idb ui` 모두 핀치 없음). macOS
Simulator 의 Option-핀치 규약을 **CGEvent 로 합성**해 뚫었다 — 정본 `evidence/pinch.swift`,
창 좌표는 System Events 한 줄로 얻는다. 접근성 권한은 이미 승인 상태(팝업 0).

| 무엇 | 결과 |
|---|---|
| 확대 후 '원래대로' pill 위치 | 상단 bar 밖 (content y≈74) — 종전 y≈21 은 띠 안 |
| pill 실제 탭 | **눌린다.** 확대 해제됨 |
| 해제 후 프레이밍 | 확대 전과 **픽셀 단위로 동일** (다른 픽셀 0 / 3,162,132) |
| 팬 추종 (60pt 드래그) | 40pt 이동, 잔차 6.45 (이동 0 일 때 62) = **67%** |

팬 67% 는 `(N−1)/N` — 첫 move 표본이 기준점으로 소비되는 구조(표본 3개)다. 실제 손가락은
표본이 수십 개라 보이지 않는다. 버그였다면 나왔을 값은 절반 + 자기상쇄 판정으로 ~33% 이고,
두 측정(40pt→30pt=75%, 60pt→40pt=67%)이 모두 그 두 배라 판정이 갈린다.

**아직 실물로 못 본 것** (belle 실기기 몫):
- 음성 큐 '크게 보기' → 자동 재개 없음 (#3 수리). 오디오 기본 꺼짐이라 시뮬에서 큐가 안 뜬다.
- 전체화면 자막 띠에서의 핀치 (#6). 자막이 뜨려면 재생 + 큐가 필요하다.
- 두 손가락 핀치의 **감각**(초점이 손가락 아래 머무는가) — 합성 이벤트로는 수치만 잰다.
