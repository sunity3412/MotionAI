## 1. 대조할 물건이 어디 있나

### 1-1. 시안 (피그마)

**★ 함정부터.** 피그마 페이지에 `분석 디자인 업데이트` 라는 이름의 **섹션
`256:506` 이 있는데 그 안은 비어 있다.** 2026-09-09 실측: 그 노드로
`get_screenshot` 을 부르면 `contentsOnly` 를 켜든 끄든 **흰 화면**이 온다.
이름만 보고 그 노드로 가면 시간을 버린다.

**시안이 실제로 있는 곳:**

```
fileKey  jrdI7kp245HkPfLB0nclsz
nodeId   254:1979        ← 이름은 "Group 55" (내용과 무관한 이름)
         └ 254:506 "모션 1"  ← 그 아래는 전부 vector
원본 크기 6714 x 5468
```

받는 법:
```
mcp__claude_ai_Figma__get_screenshot(
  fileKey="jrdI7kp245HkPfLB0nclsz", nodeId="254:1979", maxDimension=<원하는 해상도>)
```
→ 짧은 수명의 URL 이 오므로 `curl -L -o` 로 즉시 내려받을 것.

**★ 5장의 개별 노드 ID 는 없다.** 다섯 칸이 전부 한 그룹 안의 vector 라
이름으로도 텍스트로도 못 찾는다 ([[figma-redesign-section-is-vector-only]]).
**좌표로 자르는 수밖에 없다.** 렌더 폭 대비 비율 (좌, 상)–(우, 하):

| 칸 | 좌 | 상 | 우 | 하 |

| 3 교정포인트 | 0.6350 | 0.0386 | 0.8914 | 0.4111 |
| 4 보완운동 | 0.0357 | 0.4575 | 0.3171 | 0.8309 |
| 5 교정포인트2 | 0.3536 | 0.4575 | 0.8079 | 0.8309 |

(1400x1141 렌더에서 검정 테두리를 검출해 구한 값. 각 칸 안에는 **왼쪽 레퍼런스
(옛 화면) / 오른쪽 시안(새 화면)** 두 대가 들어 있다 — 오른쪽이 대조 대상이다.)

## 2. 구현하며 정한 것 (대조 때 "왜 다르지?" 하고 걸릴 것들)

시안과 **일부러 다르게** 한 것들이다. 다시 발견하고 되돌리지 말 것.

| 항목 | 시안 | 구현 | 근거 |
|---|---|---|---|
| 브랜드 빨강 | `#E94D37` | **`#FF4B33` 유지** | belle 09-08 판정. 시안 안의 레퍼런스 스크린샷을 내부 대조군으로 써서 "진짜 다른 색"임을 확인한 뒤 물었고, belle 이 기존 색 유지로 답했다 |
| 동작비교 옵션 칩 | 2개 1줄 | **4개 2줄** | 확대 문(`가로로 크게 보기`)·`음성 안내` 를 belle 이 남기라 했다 |
| 감점 행 활성 표식 | (시안에 없음) | 채움 띠 + 감점 대비 상승 | belle "테두리 같은 간단한 표시". RN `borderWidth` 는 레이아웃을 밀고 hairline 과 겹쳐 렌더 깨짐으로 읽혀서 **수단을 바꿨다** (`ResultMomentList.tsx` 15~37행에 이유 전부) |
| 시작점 맞추기 | (시안에 없음) | 접기 한 줄 | belle 08-07 "끄지 않는다". 지우지 않고 접었다 |
| 글자 크기 | — | 설명문 9pt | 시안 실측이 8pt 인데 앱 최소(10) 아래라 9로 올렸다 (`ResultExerciseTab.tsx:194`) |

**숫자·문구가 시안과 다른 것은 정상이다** — 시안은 임의 숫자고(belle "화면만 하면돼
임의 숫자임") 구현은 실제 분석 데이터를 그린다. 시안은 감점 4~5개, 대조에 쓴 문서는
감점 1개다. **감점이 여러 개인 문서로 대조하려면 §4 를 볼 것.**

## 3. 무엇이 확인됐고 무엇이 안 됐나 (관측)

**확인된 것 (시뮬레이터에서 내가 직접 열어봄, 2026-09-09):**
- 요약 / 동작비교 / 교정포인트 / 보완운동 4탭이 렌더된다
- 교정포인트의 `교정 방법 자세히 보기` → 시안 5 시트가 열린다
- 네 탭 다 세로 스크롤이 안 생긴다 (감점 1개짜리 문서 기준)

**확인 안 된 것:**
- **치수 대조 전무.** 여백·간격·모서리·글자 크기·색을 시안과 맞춰본 적 없다
- **감점 여러 개인 문서로 안 봤다.** 시안처럼 4행이면 스크롤이 생기는지 모른다
- **실기기 안 봤다.** belle 확인 대기 (시뮬레이터와 폰트 렌더가 다를 수 있다)
- **관절선 끄기 칩은 화면에 안 나온다** — 기존 분석 문서에 `imageUrlPlain` 이
  없어서다. 새로 분석해야 나온다. 대조 때 "칩이 없네"는 결함이 아니다

## 5. belle 판정 대기 (내가 먼저 꺼낼 것)

**감점 항목마다 있던 '강사에게 물어보기' 가 없어졌다.** 시안이 감점 카드
(`DeductionCard`)를 걷어내면서 그 진입점이 같이 사라졌고, 사용자가 담은 질문
(`userQuestions`)이 항상 빈 배열이 됐다. 보완운동 탭의 '강사에게 확인할 점'
(AI 자동 생성)이 비슷한 필요를 덮지만 **사용자가 직접 담는 길은 없다.**
중복 제거가 아니라 기능 소멸이라 belle 이 살릴지 결정해야 한다.

## 7. 이 섹션에서 걸렸던 함정 (같은 데 빠지지 말 것)

- **피그마 섹션 이름을 믿지 말 것** — `분석 디자인 업데이트`(256:506)는 빈 껍데기,
  실물은 `Group 55`(254:1979). §1-1 참조
- **시안에 텍스트 레이어가 0** — 이름 검색도 텍스트 검색도 안 걸린다. 모양은 SVG
  패스로 받고, 한글 글자 크기는 **자당 advance** 로 역산할 것 (검증: "75"가 폭·
  높이 양쪽에서 74pt)
- **여러 줄 편집은 반드시 줄 번호 내림차순** — 오름차순으로 넣다가 무관한 줄을
  덮어썼다
- **`.planning` 경로는 리포 루트 기준** — 이 섹션에서 cwd 가 `app/` 이라 한 번
  헤맸다
- **죽은 코드 일괄 제거 시**: 여러 줄 삼항식은 괄호 깊이 0 만으로 안 끝나고,
  여러 줄 반환 타입 함수는 본문 중괄호를 연 뒤에만 `}` 로 끝나며, 여러 줄 import 의
  이어지는 줄이 비었다고 문 전체를 지우면 살아있는 심볼이 날아간다. 구조분해
  (`const [x, setX]`)는 형제가 살아있을 수 있으니 기계에서 빼고 손으로 볼 것
  (setter 만 살아있는 게 4건이었다)
