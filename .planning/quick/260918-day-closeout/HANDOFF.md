## 7. 함정 (밟으면 시간을 태운다)

1. ★ **Pod 네트워크 볼륨 리포는 썩는다.** 오늘 로컬 브랜치 13개 잔재 + `local-0903b` 가
   **파일시스템 수준으로 깨져** git 이 D 상태로 물린다(load 7). git 을 부르지 말고
   `.git/refs/heads/<이름>` 을 **파일로 지우고** `packed-refs` 에서도 뺄 것.
2. ★ **macOS 에서 tar 로 Pod 에 코드를 밀지 말 것** — AppleDouble `._*` 가 302개 생겨
   `git checkout` 이 막힌다. 지울 땐 블랭킷 `git clean` 금지, `find -name '._*' -delete`.
3. ★ **Pod 작업 전에 push.** 부트스트랩의 `git pull origin main` 은 미푸시를 못 받는다.
   ([[gsd-pod-work-push-first]] 가 이미 그렇게 적어뒀는데 29개가 쌓여 있었다.)
4. **`/workspace/start_server.sh` 는 리포 사본이다** — md5 가 다르면 Pod 것이 낡았다.
5. **health 의 `commitSha` 를 볼 것** — 서버가 어느 코드로 도는지 추측할 필요가 없다.
6. **rsync 는 Pod 에 없다.** tar 파이프나 scp 를 쓸 것(단 함정 2 주의).
7. **병목은 GPU 가 아니다** — 88MB 분석 352초 중 s3_download 156초, GPU 추론은 11.9초.
8. 09-17 인계서 §7 함정 1~9 중 **1번(Omni)은 종결**, 나머지는 유효.
