# Quick 260923-weq — Pod 영상 다운로드 멎음을 S3 가속 엔드포인트로 우회 + fixture 10편 재분석

## 판정

**다운로드는 고쳤다(30분 → 1~3.5초). 재분석 10편 완주 — 정타 5/5 = 100, 실수 변별 4/5(kip-up 만 0), 어제와 같다.**
오늘 고친 결함 2건(감점 창·Gemini still)이 fixture 점수를 깨뜨리지 않았다.
단 **같은 영상이라도 GPU 종류가 다르면 관절 각도가 일부 프레임에서 달라진다**(8/8) — 실수 영상 점수가 ±3~7 움직였다.

## 관측

### 1. 다운로드 `[확인]`
- Pod 일반 egress(Cloudflare 30MB) 59MB/s. **서울 S3 직결 30MB: 4회 중 3회 5~7KB/s**(연결 단위 멎음). 호스트 교체(4090→L4)로도 같음.
- **가속 엔드포인트 30MB 4/4 8.5~8.7MB/s.** 버킷 가속 ON + `S3_USE_ACCELERATE=1` → 10편 s3_download **1.1~3.5초**
  (수리 전 첫 편 1,780초). 편당 총 90~161초.

### 2. 재분석 결과 (09-22 208dc500 · RTX 4090 → 오늘 86fa0f89 · L4, power-spin 정타만 4090)

| 동작 | 정타 | 실수 09-22 → 오늘 | 각도 동일? (>5° 프레임 비율) |
|---|---|---|---|
| power-spin | 100 → 100 | 66 → **73** | 정타 동일(4090↔4090) / 실수 16% |
| kip-up | 100 → 100 | 100 → **100** | 정타 동일(L4↔L4) / 실수 7% |
| climb | 100 → 100 | 89 → **86** | 정타 8% / 실수 16% |
| peter-pan | 100 → 100 | 85 → **80** | 정타 13% / 실수 11% |
| pdshape | 100 → 100 | 87 → **87** | 정타 3% / 실수 0%(max 0.8°) |

veto 상태(applied/not_applicable)는 10/10 그대로. 정타 5편은 감점·억제 0건 그대로.

### 3. ★ GPU 종류가 각도를 바꾼다 `[확인: 같은 종류 2/2 동일, 다른 종류 8/8 다름]`
09-22 kip-up 정타는 L4 Pod(교체 전) 결과였고 오늘 L4 와 **max 0.0°**. power-spin 정타는 4090↔4090 **0.0°**.
나머지 8편(4090↔L4)은 전부 다르다 — 차이는 **연속 구간에 몰려 있다**(power-spin 실수: 5~9·14~16·35~39 프레임,
왼어깨·왼엉덩이 약 20°씩). 무작위 잡음이 아니라 특정 프레임에서 좌표 해가 바뀐 모양.
`RTMW_DETERMINISTIC=1` 은 같은 GPU 안에서의 결정론이다.
→ 기준 대비 관절 편차가 최대 ~5° 움직이고(power-spin 왼어깨 31.9→26.0, peter-pan 32.7→36.7) 감점 목록이
바뀐다(climb: 왼어깨 감점 → 오른엉덩이 감점). **같은 영상이 GPU 에 따라 실수 점수 ±3~7.**

### 4. power-spin 정타 stability 84 → 96, 각도는 동일 `[추정]`
각도·DTW 거리 완전 동일인데 안정도 차원만 움직였다. 오늘 recognizer 8.1초(신규 Gemini 호출) vs 09-22 0.4초(캐시).
안정도 창은 recognizer 의 hold window 로 잘리므로 **Gemini 가 준 국면 창이 달랐다**고 본다 — 창 자체는 doc 에
안 남아 직접 대조는 못 했다. 종합 점수(감점 합산)에는 안 들어가는 차원이라 100 은 그대로.

### 5. 오늘 수리 2건의 효과 `[미확인 — GPU 변수와 섞임]`
감점 창(sqt): 10편 전부 창 [0, 기준 전체) 라 no-op 확정. Gemini still(u2q): veto 상태 10/10 불변, 짚은 관절 불변.
still 이 바뀐 것이 판정을 바꿨는지는 각도까지 같이 바뀌어서 가를 수 없다. **확실한 것 = 나빠지지 않았다.**
