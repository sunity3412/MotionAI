# 킵업(잘된 예시) 영상 분석

| 항목 | 내용 |
|---|---|
| 분석 파일명 | v10_kip-up_correct.mp4 |
| 원본 파일명 | fixtures:kip-up-correct.mp4 |
| 길이 | 약 7.8초 |
| 해상도 / fps | 2160x3840 (세로) / 30fps |
| 분석 프레임 수 | 총 69프레임 (전체 3fps 24프레임 + 정밀 10fps 구간 45프레임: 0.5~2.5s, 3.0~4.2s, 6.5~7.7s) |
| 촬영 환경 | 실내 스튜디오, 천장 고정형 폴 1개, 측면 고정 1캠 (잘못된 예시 v04와 동일 장소·동일 구도) |

> 라벨은 "킵업(kip-up) 잘된 예시"이나, 아래 분석은 프레임에서 실제로 관찰된 동작만을 기준으로 서술함.

## 1. 시간축 segmentation

| 구간 | 시간 | 동작 |
|---|---|---|
| S0 | 0.0 ~ 1.0s | Entry: 폴 향해 스텝 어프로치 → 양손 그립 셋업 → 점프 이륙 (약 0.95~1.0s에 양발 이지) |
| S1 | 1.0 ~ 2.0s | 스윙 회전 1회차 (다리 사이드 스윕 → 후방 통과 시 와이드 스트래들) |
| S2 | 2.0 ~ 3.7s | 스윙 회전 2회차 (전면 통과 시 상체 후굴 + 다리 모음 → 후방 스트래들) |
| S3 | 3.7 ~ 5.4s | 스윙 회전 3회차 (동일 사이클 반복) |
| S4 | 5.4 ~ 7.2s | 스윙 회전 4회차(마지막) → 감속 → 착지 (약 7.0s 첫 접지, 7.2s 양발 안착) |
| S5 | 7.2 ~ 7.8s | 마무리: 한 손 폴 그립 유지한 스탠딩 피니시 포즈(런지 형태)로 종료 |

- 회전 주기 판별 기준: 등이 카메라를 향하는 와이드 스트래들 통과 시점 = 약 1.95s, 3.65s, 5.35s. 주기 약 1.7초로 거의 일정.
- 총 회전수: 이륙(1.0s)부터 첫 접지(약 7.0s)까지 약 3~3.5회전(약 1080°~1260°). ±0.5회전 오차 가능(측면 1캠 한계).
- 이륙(1.0s) 이후 첫 접지(약 7.0s)까지 약 6초간 바닥 접촉 없음 — 3fps 전체 + 10fps 정밀 구간 모두에서 무접지 확인. 단, 10fps로 보지 않은 중간 구간(2.5~3.0s, 4.2~6.5s)의 순간 터치는 완전 배제 불가하나, 해당 구간 3fps 프레임에서 발끝이 모두 바닥에서 충분히 떠 있어 가능성 낮음.
- **인버전(골반이 머리 위로 가는 전환) 발생 여부: 미발생.** 0.5~2.5s(이륙·가속 구간), 3.0~4.2s(중간 회전), 6.5~7.7s(착지)를 10fps로 정밀 확인한 결과를 포함해, 분석한 69프레임 전체에서 골반·다리가 어깨/머리 위로 올라가는 장면이 없음. 머리가 항상 골반보다 위에 있음.

## 2. 각 segment의 자세 description

### S0 (0.0~1.0s) — Entry [transition]
- 신체 정렬: 직립(수직). 폴 옆에서 팔을 벌려 어프로치(0.0s) → 스텝-인하며 폴 잡기.
- 폴 접촉점: 0.33s경 한 손(오른손)이 어깨~머리 높이에 먼저 그립 → 0.7~0.9s 반대팔이 머리 위로 스윕하여 오버헤드 신전 그립 완성. 최종 그립 = 양손: 윗손 오버헤드 팔 신전 + 아랫손 얼굴~가슴 높이 (이륙 시퀀스 기준 윗손=왼손으로 판단되나, 회전 중 시점 변화로 좌우가 반전되어 보이는 컷이 있어 좌우 표기는 이륙 시퀀스 기준임).
- 다리 자세: 스텝 후 발끝 포인으로 밀어 점프 이륙(0.95~1.0s). 비대칭(한 발 추진).
- 구분: transition (이륙 준비~이륙).

### S1~S4 전반 (1.0~6.9s) — 모멘텀 스윙 회전 약 3.5회 [transition 연속, hold 없음]
- 신체 정렬: 직립~후방 사선 매달림이 전 구간 유지. 전면 통과 시 상체를 뒤로 젖히는 후굴(아치)이 들어가며 몸통이 수직에서 약 30~45° 기울지만, 수평 이하로 내려가거나 거꾸로 되는 장면 없음.
- 폴 접촉점: 양손 그립만 사용(윗손 오버헤드 신전 + 아랫손 가슴 높이). 다리·몸통의 폴 접촉(훅, 끼우기)은 전 구간 미관찰. **그립 높이가 전 구간 유지됨** — 벽 스피커(고정 지형지물) 기준으로 1.0s와 6.3s의 윗손 높이가 동일, 슬립/흘러내림 없음.
- 다리 자세 (한 회전 내 사이클, 반복 관찰됨):
  - 측면~전면 통과: 양다리를 모아 한쪽 사선으로 길게 뻗는 스윕(크레센트 라인, 예: 3.0s, 5.0s) 또는 전후 가위 분리(예: 2.0s, 3.3s) + 상체 후굴.
  - 후방(폴 뒤) 통과: 양다리 와이드 스트래들(V자), 좌우 대체로 대칭, 무릎 신전 + 발끝 포인 (예: 1.95s, 3.65s, 5.35s).
  - 전 구간 무릎 신전과 발끝 포인 유지, 라인 명확.
- 구분: 전부 transition(동적 스윙). 2초 이상 정지 유지되는 hold 자세 없음.
- 회전 방향: 일정 방향 회전은 확인되나 시계/반시계 단정은 측면 1캠 특성상 확정 불가, 추가 영상 각도 필요.
- 폴 모드(스핀/스태틱): 영상만으로 확정 불가. 회전 주기가 약 1.7초로 감속 없이 일정한 점은 스핀 폴 가능성을 시사하나, 폴 자체의 회전 여부는 이 화질·각도에서 식별 불가.

### S4 후반 (6.9~7.2s) — 착지 [transition]
- 6.8~6.9s: 회전 감속과 함께 몸을 세우고 다리를 아래로 내림.
- 약 7.0s: 한 발 첫 접지(발끝부터) → 7.1~7.2s: 반대발 순차 접지, 넓은 스탠스로 안정화. 휘청임·추가 스텝 없이 한 번에 안착.
- 폴 접촉점: 착지 중에도 윗손 그립 유지.

### S5 (7.2~7.8s) — 피니시 포즈 [hold(지상)]
- 신체 정렬: 직립. 한 손을 폴 위쪽에 뻗어 잡은 채 런지 형태의 스탠딩 포즈, 시선 위.
- 폴 접촉점: 한 손(윗손)만 유지, 반대손 해제.
- 다리 자세: 앞다리 지지 + 뒷다리 후방 신전, 발끝 포인.
- 구분: 지상 마무리 포즈(공중 기술 아님).

## 3. IPSF Code of Points 매칭

| 구간 | 매칭 결과 | 근거 |
|---|---|---|
| S0 (Entry) | IPSF 미등재 (기본 어프로치/점프 이륙) | 코드화된 기술 요소 아님 |
| S1~S4 (모멘텀 스윙 ~3.5회전) | **IPSF 미등재 (학원 통용: "킵업" 스윙)** — 굳이 근사하면 ≈ Dynamic Combinations(DC)에서 쓰이는 모멘텀 스윙 variation | 회전 중 자세가 매 반회전마다 변형(스트래들↔모음 스윕)되어 "정적 자세를 유지한 회전"이라는 Spins 정의(static 360°/spinning 720°)에 부합하지 않음. Climbs(상승 없음), Holds(정지·훅·인버전 없음), Splits(인버전 고정 자세 없음) 전부 매칭 불가 |
| S5 (피니시) | IPSF 미등재 (지상 포즈) | 채점 요소 아님 |

- Holds 계열(Outside/Inside Leg Hang, Cupid, Pencil, Ayesha, Iron X, Jade, Butterfly, Deadlift) 매칭: 전부 불가 — 다리 훅, 인버전, 공중 정지 유지가 관찰되지 않음.
- Splits 계열(Inverted Split, Marchenko) 매칭: 불가 — 공중 전후 다리 분리는 0.3초 내외의 통과 동작이며 인버전이 아님.
- 회전량 자체(약 1080° 이상)는 Spins의 spinning 기준(720°)을 수치상 초과하지만, 위와 같이 "자세 유지" 요건이 충족되지 않아 Spins 정확 매칭으로 표기하지 않음.
- **라벨 용어에 대한 중요 소견**: 잘못된 예시(v04) 분석 당시 "킵업 = 스윙으로 인버전에 진입하는 동작이며 인버전 부재가 오류"라는 가설을 기록했으나, **잘된 예시인 본 영상에도 인버전이 전혀 없음**. 따라서 이 라벨 체계에서 "킵업"은 인버전 진입 기술이 아니라 **"점프 이륙 → 양손 그립 모멘텀 스윙 회전 → 착지"로 구성된 스윙 기술 자체를 가리키는 학원 통용 명칭**으로 보는 것이 타당함(v04 분석의 해당 가설은 수정 필요). 정확한 학원 측 정의는 영상 외 정보가 없어 확정 불가.

## 4. 채점 기준 메모

- 카테고리: 정식 등재 기술 아님. IPSF 채점 체계 관점에서는 Combos(Dynamic Combinations)의 연결/모멘텀 요소 성격. 단독 점수 요소로 인정될 Spin/Hold/Climb/Split은 영상 내 없음.
- 난이도: 미등재이므로 공식 난이도(Simple~Extremely Difficult) 부여 불가. 형태상 양손 그립·비인버전 스윙으로 기초~중급 수준의 동작군에 해당.
- "잘된 예시"로서 관찰되는 수행 품질 요소 (프레임 근거):
  1. **체공 유지**: 이륙(1.0s)부터 착지(7.0s)까지 약 6초·약 3.5회전 동안 무접지 유지.
  2. **그립 높이 유지(슬립 없음)**: 고정 지형지물(벽 스피커) 대비 손 위치가 처음부터 끝까지 동일 — 회전 중 몸이 흘러내리지 않음.
  3. **일정한 회전 리듬**: 회전 주기 약 1.7초로 감속 없이 유지.
  4. **라인 품질**: 전 구간 무릎 신전·발끝 포인, 후방 스트래들의 좌우 대칭, 전면 통과 시 후굴 라인 명확.
  5. **완결성**: 감속 → 발끝부터 순차 접지하는 컨트롤된 착지(7.0~7.2s) → 피니시 포즈(7.2~7.8s)까지 동작이 완결됨. (잘못된 예시 v04는 착지·마무리 없이 스윙 중 종료된 것과 대비되는 지점. 단 v04의 종료는 촬영 컷일 가능성도 있어 단정 불가.)
- 채점 핵심(이 기술을 평가한다면): 체공 중 그립 높이 유지, 회전수, 스트래들 대칭과 포인, 후굴 라인, 착지 컨트롤.

## 5. 종합

- 영상 전체는 **단일 동작**임 (콤보 아님): "스텝 어프로치 → 양손(오버헤드+가슴 높이) 그립 점프 이륙 → 폴 주위 모멘텀 스윙 약 3.5회전(후방 스트래들 ↔ 전면 후굴·다리 스윕 사이클) → 컨트롤된 착지 → 스탠딩 피니시 포즈"의 한 시퀀스.
- 인버전·다리 훅·클라임·정지 hold는 전혀 포함되지 않으며, 10fps 정밀 확인에서도 인버전 전환은 미발생.
- 잘못된 예시(v04)와 동일한 계열의 스윙 동작이며, 본 영상은 착지와 마무리까지 포함된 완결 수행임. 두 영상 모두 인버전이 없으므로 이 라벨 체계의 "킵업"은 모멘텀 스윙 기술 자체를 지칭하는 학원 통용 명칭으로 판단됨 — IPSF 정식 등재 기술로는 매칭 불가.
- 잔여 불확정 사항: 폴 모드(스핀/스태틱), 회전 방향(시계/반시계), 정확한 회전수(±0.5), 그립 좌우 손 구분 — 측면 1캠 한계로 확정 불가, 추가 영상 각도 필요.
