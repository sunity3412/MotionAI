## 3. 플랭크 스핀 (Plank Spin)

**기본 정보 — 여기 좀 다를 수 있어요**

영상 보니까 두 단계가 명확히 나뉘는 동작이었어요:

```
1단계 (0~5초): 가슴을 폴에 붙이고, 머리는 다리 위로 가는 측면 자세
              왼발 굽힘 + 오른발 신전

2단계 (6초~): 머리가 아래로 내려가고 (인버트),
             양 다리를 일자로 찢어 스플릿
```

**확인 부탁드릴 것**
- 이 동작 이름이 정말 **플랭크 스핀**인가요? 아니면 다른 이름이 있나요?
  - (A) 그대로 플랭크 스핀
  - (B) 다른 이름: ____
  - (C) 사실 두 동작의 콤보다 — 1단계는 ____, 2단계는 ____

- 난이도: **중급** — 맞나요?
  - (A) 중급 그대로
  - (B) 고급 (다리 찢기 + 인버트가 들어가니까)
  - (C) 기초

- 진입 방식: **팔을 굽혀서 끌어올리는 리프트** — 맞나요? ( ✓ / ✗ )

**좌우 정보 (영상에서 확인됨)**
- 왼손 위쪽 그립 + 오른손 보조 (양손 그립) ✓
- 시계 방향 회전 ✓

**확인 부탁드릴 것**
- 두 단계 중 어느 쪽이 더 채점 우선순위가 높나요?
  - (A) 1단계 측면 플랭크
  - (B) 2단계 인버트 스플릿
  - (C) 두 단계 전환의 매끄러움이 가장 중요

- 학생들이 이 동작에서 자주 틀리는 부분 1~2개:

## 4. 인버트 버터플라이 콤보 (Invert Butterfly Combo)

**기본 정보**

영상 보니까 이 콤보는 **앞 6초가 플랭크 스핀과 완전히 같은 동작**이에요. 그 다음에:

```
6~9초:    왼쪽 무릎으로 폴 감싸기, 오른쪽 다리 펼침
9~12초:   다리 교환 (오른쪽 무릎 폴 감싸기, 왼쪽 다리 펼침)
15~21초:  다리 일자로 찢기를 수직 자세로 유지 (왼쪽 다리 위) ← 가장 인상적
22초~:    폴 잡고 올라오며 마무리
```

**확인 부탁드릴 것**
- 이 동작 이름이 **인버트 버터플라이 콤보**가 맞나요?
  - (A) 맞음
  - (B) 다른 이름: ____

- 난이도: **고급** — 맞나요? ( ✓ / ✗ → 정정: ____ )

- 콤보 중 가장 중요한 자세(채점 우선순위)는 어느 구간인가요?
  - (A) 0~6초 (플랭크 + 인버트 베이스)
  - (B) 6~12초 (다리 교환)
  - (C) 15~21초 (수직 스플릿)

- 학생들이 이 콤보에서 가장 어려워하는 부분은?
  - (A) 진입 (리프트)
  - (B) 다리 교환
  - (C) 수직 스플릿 유지
  - (D) 마무리 (폴 올라오기)
  - 자세한 설명: ____
